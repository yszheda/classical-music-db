# 雷格：基于巴赫和泰勒曼主题的变奏与赋格

人们常说喜剧是悲剧加上时间的沉淀，同样也可以争辩——虽然简单化——艺术上的卓越往往是死亡和时间的结果。（要证实这一点，只需看1950年版《格罗夫词典》对拉赫玛尼诺夫——雷格同时代的音乐对立面——的贬损论战即可。）对于那些如詹姆斯·迪恩所言"活得快，死得早，留下美丽遗体"的人，如门德尔松、莫扎特、舒伯特，神化的快车道几乎是必然的。然而，很少有伟大艺术人物像马克斯·雷格这样，受到如此两极分化的评价：一方面被称为"巴赫之后最伟大的德国作曲家"，另一方面又被形容为"幽闭恐怖和便秘"。他以其锋利的机智和喜欢文字游戏而出名（他身材相当魁梧，却会双关地称自己为"Rex Mager"[瘦子]，并且常常自贬地提到他姓氏本身就是回文），以及他对批评家那些不敬的反驳——著名的例子是他告诉一位批评家，他现在和批评文章一起在最小的房间里，但很快这篇文章就会到他"身后"了！——这些都和他的音乐一样出名。

雷格出生于巴伐利亚，最初随父亲学习，后来在松德斯豪森和威斯巴登继续跟随胡戈·里曼学习，在那里他担任集市教堂的管风琴师，并在音乐学院任教。通过管风琴家卡尔·施特劳贝的提携，他作为管风琴作曲家赢得了声誉。从1907年到1908年，他担任莱比锡大学音乐总监，并从那时起到他悲剧性早逝一直在莱比锡音乐学院教授作曲。他在德国本土以及奥地利、瑞士、荷兰和俄罗斯进行巡回音乐会演出，并在1909年访问伦敦时介绍了他的许多室内乐作品。他极其庞大而多样的作品在他生前被认为是激进和革命的，因此引发了激烈的个人和专业争议。当时拒绝标题音乐、倡导"绝对音乐"是不时尚的——而布拉姆斯——正如雷格一样——无疑是变奏形式的大师。除此之外，雷格还一贯追求复调与对位的卓越与复杂性，这在当时被认为是过时的；他完全无视传统和声领域既成的智慧，他对宏大、不妥协的音乐结构惊人的掌控力至今依然令人惊叹。

本专辑中两首作品中较早的一首《基于J.S.巴赫主题的变奏与赋格》创作于1904年。主题来自巴赫第128号康塔塔《基督升天》中女低音和男高音的二重唱"他的全能"。雷格这部作品拥有极深的深度和复杂性，在前两首相对"直接"的变奏之后，后续变奏不断向意想不到的和声与节奏方向反弹——时而在火热、半音模糊的氛围中隐约暗示主题，时而又调整乐句长度，时而又孤立节奏细胞，同时显然将主题粉碎成微粒，检视其细节，然后再解构或重建整体。这部作品充溢着无穷无尽的色彩、创意，在音乐、结构和钢琴技法上的运用令人惊叹。要详细描述这十四个变奏中的每一个都是徒劳的，因为它们本身就能用无限更大的口才诉说自己，无论如何，每一个都从属于整体结构。然而，雷格在结尾庞大的赋格中超越了自我，它由两个看似独立却又相互依存的宏大四声部赋格组成，最后以一个"地狱奇观"的结局将两者融合在一起。

与这部巨作黑暗、近乎不祥的性格相比，1914年的《基于G.P.泰勒曼主题的变奏与赋格》呈现出令人惊讶更轻盈、甚至可以说更俏皮的风格。主题取自泰勒曼1730年代一套组曲（序曲）中的小步舞曲，这套组曲被收录在他著名的《餐桌音乐》中。雷格的这些变奏由坚定的雷格支持者、也是本作品受赠者詹姆斯·克瓦斯特的妻子弗里达·克瓦斯特-霍达普首演，四年之前她刚刚首演了作曲家宏大的f小调钢琴协奏曲作品114，而那部作品正是题献给她的。

对于雷格来说，这部作品更平易近人且更愉快的性质看似矛盾——尤其是当你将它与之前那首巴赫作品的阴郁动荡相比，并且想到雷格距离他不幸早逝已经很近——事实上，它看起来散发着生命肯定的光芒。（可以比较舒伯特，他去世时比雷格此时只年轻十二岁，他晚期作品如弦乐五重奏和降B大调钢琴奏鸣曲，听者如果不知道创作背景，会感受到痛苦和甜蜜交织，但不会明显感觉到死亡幽灵的存在。）撇开死亡预兆不说，全部二十三个变奏都比巴赫变奏那组更不斜出切线、更自然音阶，主题和结构上也更清晰连接。它们不可阻挡的进程继续保持着愉悦、跳跃、有时闪闪发光，而大部分时候都轻松愉快（除了两个更黑暗的降B小调慢变奏第十六和十七，它们更像乳白色石榴石而非"黑珍珠"）。最后的赋格曾经被认为无法演奏，现在听来比巴赫变奏的赋格密度更低、更少卷曲，并且拥有更透明、甚至嬉戏般的感觉，这种感觉类似雷格为管弦乐队创作的著名莫扎特变奏中对应的乐章。

由于CD格式的时间限制，在泰勒曼变奏中必须对乐谱中标示的反复做出一些任意决定。因此，在主题初次陈述之后，每个变奏只保留了前半部分的反复。

## 马克·拉蒂默

马克·拉蒂默在美国被比作巴雷尔，在大西洋彼岸被比作霍洛维茨，《卫报》称他为"钢琴作者"，让人联想到十九世纪和二十世纪异国情调钢琴家/作曲家的形象，而《卡登斯》杂志称他为"近年来最具创新性的音乐家之一"。无论是在高雅艺术还是大众文化中他都能挥洒自如，他的音乐策略总是处于边缘，总是位于光谱完全对立的两端。他在广阔的音乐领域已经被证明拥有可靠的记录，他包罗万象的曲目范围体现在超过100首首演，对非主流杰作巨大体积的演绎，以及对技术和脑力要求极高的近乎不可能的作品、作曲委约、多媒体和跨艺术形式即兴创作、当代/先锋爵士实验。

他能在如此多不同领域成功且不妥协的巨大能力，被当今许多顶尖音乐记者和同行所称赞，这让他得以在世界一些最重要的国际古典音乐节和爵士音乐节上登台演出。他的唱片目录也展现出无与伦比的广度和深度，从阿尔坎著名的《独奏钢琴协奏曲》的首次现场录音（1999年），到实时场地特定独奏自由爵士即兴（2001年）。令人激动、原创且常常富有远见，拉蒂默迅速在当今古典、即兴和当代爵士界确立了令人敬畏创作力量的声誉。

# 雷格：基于巴赫主题的变奏与赋格
基于泰勒曼主题的变奏与赋格

人们常说喜剧是悲剧加上时间的沉淀，即使这有点简单化，你依然可以主张艺术上的卓越往往是死亡加上时间的结果。在1950年代版《格罗夫音乐词典》中，我们能找到一个很好的例子，对同时代雷格的对立面拉赫玛尼诺夫的批评。对那些像詹姆斯·迪恩所说"活得快，死得年轻，留下美丽尸体"的人来说，立刻神化几乎是必然的——比如门德尔松、莫扎特和舒伯特。然而，很少有伟大艺术人物像马克斯·雷格这样，受到如此极端分歧的评价：一方面说他是"巴赫之后最伟大的德国作曲家"，另一方面又说他"幽闭恐怖且便秘"。他因锋利的机智和喜欢文字游戏而出名（他身材相当魁梧，用易位构词自称"Rex Mager"[瘦子]，并且对姓氏回文进行自嘲），他对批评家那些不敬的回答也很有名（他曾告诉一位批评家，他现在和他的冒犯文章一起在最小的房间里，但很快文章就会到他身后了！），这些都不亚于他的音乐。

他出生于巴伐利亚，雷格最初随父亲学习，然后在松德斯豪森和威斯巴登跟随胡戈·里曼学习，在那里他成为集市教堂的管风琴师并在音乐学院教书。在管风琴家卡尔·施特劳贝支持下，他作为管风琴作曲家确立了声誉。从1907到1908年，他担任莱比锡大学音乐系主任，并在莱比锡音乐学院教授作曲，直到他悲剧性过早去世。他在德国本土以及奥地利、瑞士、荷兰和俄罗斯举办音乐会巡演，并在1909年访问伦敦时介绍了他许多室内乐作品。他极其庞大而多样的作品在他生前被认为是激进和革命的，因此给他带来了激烈的个人和专业争议。在那个时代，拒绝标题音乐、追随布拉姆斯提倡"绝对音乐"是不时尚的，而雷格和布拉姆斯一样，无疑是变奏大师。除此之外，雷格对复调和对位的卓越复杂性有着痴迷的追求——这在当时被认为过时——他完全无视传统和声的成见，他对巨大不妥协音乐结构的掌控即使在今天依然令人惊叹。

本唱片中两首作品中较早的那首，基于巴赫主题的变奏与赋格，日期是1904年。主题来自巴赫第128号康塔塔《基督升天》中女低音和男高音的二重唱"他的全能"。雷格的作品拥有巨大的深度和复杂性，前两首相对"古典"之后，接下来的变奏向无数意想不到的方向弹开，在和声和节奏上——时而在火热半音暧昧的温室氛围中迷人地暗示主题，时而揉捏乐句长度，时而孤立击打节奏细胞同时粉碎主题，检查细节然后解构再重建整体。作品充满了无穷无尽的色彩宝藏和意想不到的发明，在音乐、结构和钢琴技法上的运用令人惊叹。要详细描述这十四个变奏中的每一个是乏味的，因为它们本身就能用无限更多口才为自己说话，每一个都从属于整体。然而，雷格在结尾巨大赋格中超越了自我，它由两个看似独立实则相互关联的宏大四声部赋格组成，最后以一个"地狱奇观"结局将两者融合。

与这部大作黑暗、几乎威胁的性格相比，1914年的《基于泰勒曼主题的变奏与赋格》被铸造在一个令人惊讶更轻盈的模具中，甚至可以说更俏皮。主题取自泰勒曼1730年代一首序曲组曲中的小步舞曲，泰勒曼将其放入他著名的《餐桌音乐》。雷格的变奏由一位坚定的雷格倡导者首演，她就是作品受赠者詹姆斯·克瓦斯特的妻子弗里达·克瓦斯特-霍达普，四年之前她已经首演了作曲家宏大的f小调钢琴协奏曲作品114，那部作品正是题献给她的。

对于雷格来说，这部作品更平易近人、更愉悦的性格看起来矛盾——特别是当你将它与更早巴赫作品的黑暗漩涡相比，考虑到雷格悲剧性早逝已经临近，它实际上看起来是令人目眩的肯定生命。（想想舒伯特，他去世时比雷格此时还年轻十二岁，他晚期作品——比如弦乐五重奏和降B大调钢琴奏鸣曲——听众如果不知道创作背景，会感受到苦乐参半深情，但不会明显感觉到写在死亡阴影下。）撇开死亡预兆不说，全部二十三个变奏都比巴赫变奏那组更少斜出、更多自然音阶，在主题和结构上连接更清晰，轮廓也更分明。它们不可阻挡的进程继续着，快乐地、跳跃地、有时闪闪发光，大部分时候轻松愉快（除了第十六和十七变奏，降b小调慢板，它们更像乳光石榴石而非"黑珍珠"）。最后的赋格曾经被认为无法演奏，它比巴赫变奏的赋格密度更低不那么缠绕，拥有更透明，甚至嬉戏般的感觉，就像雷格那些辉煌的莫扎特主题管弦乐变奏中对应的乐章。

由于CD载体的时间限制，在泰勒曼变奏的乐谱中关于反复必须做出一定程度任意决定。因此，在主题初次呈现之后，每个变奏只包含前半部分的反复。

## 马克·拉蒂默

马克·拉蒂默在美国被比作巴雷尔，大西洋彼岸被比作霍洛维茨，《卫报》称他为"作者-钢琴家"，让人想到十九世纪和二十世纪钢琴家作曲家的异国情调形象，《卡登斯》杂志称他为"近年来最具创新性音乐家之一"。他在高雅艺术和流行文化中都很自在，他总是在刀刃上探索音乐，探索所有类型甚至最对立的类型。他已经在无数音乐领域证明了自己的价值，他的曲目包含超过一百首新作，对创新杰作和实际上无法演奏的作品进行泰坦般演绎，这需要巨大技术和智力能力，他还接受众多作曲委约，你可以看到他在多媒体语境中即兴，混合多种艺术形式，他也投身当代音乐和先锋爵士实验。

他巨大的工作能力和不妥协，让他在如此多不同领域获得成功，被当今许多主要音乐批评家和同行称赞，这让他能够在最大的国际音乐节和爵士音乐节演出。他的唱片也展现出无与伦比的广度和深度，从阿尔坎著名的独奏钢琴协奏曲首次录音（1999年），到特定场地实时自由独奏爵士即兴（2001年）。令人振奋、原创且常常富有远见，拉蒂默迅速在古典音乐、即兴和当代爵士世界建立了令人印象深刻的声誉，作为惊人创作力量站稳了脚跟。

## 第12-13页（德文原文翻译）

# 雷格：基于巴赫主题的变奏与赋格
基于泰勒曼主题的变奏与赋格

人们常说，喜剧就是悲剧加上时间，如果简化来说，你可以认为艺术杰出往往是死亡加时间的结果。（要证实这个观点，你只需看看1950年版《格罗夫词典》，里面对拉赫玛尼诺夫——雷格同时代人和音乐对立面——的负面批评论战即可。）对于那些"活得快，早死去，留下漂亮尸体"的人——引用詹姆斯·迪恩的话——快速成神几乎已经保证，比如门德尔松、莫扎特和舒伯特。然而，很少有伟大艺术人物像马克斯·雷格这样，获得如此极端对立评价：一方面被称为"巴赫之后最伟大德国作曲家"，另一方面又被称为"幽闭恐怖便秘"。他同样因机智敏锐和喜好文字游戏而闻名（他身材并不小，却戏虐地将自己名字变位为"Rex Mager"[瘦子]，并且总是拿自己姓氏回文来自嘲），他对批评家的讽刺反驳也很有名——他曾告诉一位批评家："我现在和你的批评文章一起在小房间里，但很快你的批评就会在我身后。"

雷格出生在巴伐利亚，最初由父亲授课，然后在松德斯豪森和威斯巴登跟随胡戈·里曼继续学习，在那里他偶尔在集市教堂当管风琴师，并在音乐学院教书。在管风琴家卡尔·施特劳贝支持下，他作为管风琴作曲家获得了声誉。1907-1908年他在莱比锡大学担任音乐总监，并在莱比锡音乐学院教授作曲，直到1916年悲剧性早逝。他在德国、奥地利、瑞士、荷兰和俄罗斯举办音乐会巡演，1909年访问伦敦时向公众介绍了许多他的室内乐作品。他异常庞大多样的创作在他生前就被认为是激进革命的，因此给他带来了激烈的个人和专业争议。当时拒绝标题音乐、倡导"绝对音乐"并不时髦，布拉姆斯这样做了，而雷格同样是无可争议的变奏形式大师。我们还必须加上以下风格特征：雷格坚定不移地坚持复杂性，突出复调和对位成就，这在当时被认为不合时宜，他完全漠视传统和声已学规则，他对巨大、不妥协音乐建筑的掌握即使今天看了依然让人惊讶。

这张CD上两首作品中更古老的那首，基于巴赫主题的变奏与赋格，日期是1904年。主题来自巴赫第128号康塔塔《基督升天》中女低音和男高音的二重唱"他的全能"。雷格的作品拥有巨大深度和层次性，前两首相对简单之后的变奏，在和声和节奏上辐射出意想不到的可能性——一会儿它们处于激动、半音模糊的和声中，非常接近主题，一会儿又碰撞拉伸乐句长度，或是敲打孤立节奏细胞，同时主题被粉碎成最小颗粒。所有细节都被探索，分解然后重新组合。这部作品向我们倾泻出无穷无尽色彩、灵感和令人惊叹的音乐、结构和钢琴技巧。要描述这14个变奏中的每个细节是件不讨好的工作，因为它们本身就能用无限更多口才诉说，每一个都从属于整体结构。然而，在巨大的结束赋格中，雷格超越了自己。它由两个看似独立但相互关联的巨大四声部赋格组成，最后在一个"地狱奇观"中被汇聚在一起。

与这部巨作对黑暗、预感贯穿的性格相比，1914年的《基于泰勒曼主题的变奏与赋格》性格令人惊讶更轻盈，几乎可以说更嬉戏。主题取自十八世纪三十年代泰勒曼一首组曲（序曲）中的小步舞曲，泰勒曼将它放入著名的《餐桌音乐》。雷格的变奏由弗里达·克瓦斯特-霍达普首演，她是坚定雷格支持者，也是本题献者詹姆斯·克瓦斯特的妻子，四年之前她已经首演了作曲家宏伟的f小调钢琴协奏曲作品114，那部作品正是题献给她的。

这部作品更平易近人，至少对雷格来说性格更愉悦，这看起来矛盾——特别是当你和前一首巴赫作品的黑暗漩涡相比，而且你考虑到雷格过早离世已经临近——它确实看起来是耀眼的生命肯定。（你可以想想舒伯特，他去世时比雷格此时还年轻十二岁，他晚期作品比如弦乐五重奏和B大调奏鸣曲，听众如果不知道创作背景，可以感受得到深情，但不会明显感觉到死亡幽灵存在。）撇开死亡预兆，全部23个变奏都比巴赫变奏更少偏斜，第一眼看来更自然音阶，主题和结构上更明显联系在一起，比巴赫那组更清晰轮廓。它们不可阻挡进程愉快继续，多数情况下轻快，有时闪烁，大体轻松（除了降b小调第16和17变奏，它们更慢更暗，更像蛋白石石榴而不是黑珍珠）。最高点的赋格，曾经被认为无法演奏，它比巴赫变奏的赋格密度更低不那么纠缠，更透明，带来愉悦氛围，就像雷格那首美妙的莫扎特主题管弦乐变奏中对应乐章一样。

在泰勒曼变奏中，由于CD时间限制，必须对乐谱标示的反复做出一定随意决定。因此，主题初次呈现之后，每个变奏只记录了前半部分反复。

## 马克·拉蒂默

马克·拉蒂默在美国被比作巴雷尔，大西洋彼岸被比作霍洛维茨。《卫报》称他为"钢琴作者"，唤起了十九世纪和二十世纪钢琴家作曲家异国情调形象，《卡登斯》杂志说他是"近几十年来最具创新性音乐家之一"。他无论是在高雅艺术还是流行文化都能找到家，他的音乐策略总是在边缘，总是在谱系完全对立两端。通过超过100场首演，对主流之外杰作巨人般呈现，对技术和智力要求极高几乎不可能作品，他已经证明了自己。他委约作曲，多媒体演出，即兴，超越单一艺术门类界限，实验当代先锋爵士。

拉蒂默在如此多不同领域成功不妥协的伟大能力，被当今许多领先音乐记者和同行肯定，这让他能够在世界一些最重要国际古典音乐节和爵士音乐节登台。他的唱片目录也显示出他独一无二广度和深度——从阿尔坎著名独奏钢琴协奏曲首次现场录音（1999年），到特定场地实时独奏自由爵士即兴（2001年）。令人兴奋、原创且常常富有远见，拉蒂默迅速在当代音乐界建立了令人敬畏创造性力量的名声，无论是古典、即兴还是当代爵士。
