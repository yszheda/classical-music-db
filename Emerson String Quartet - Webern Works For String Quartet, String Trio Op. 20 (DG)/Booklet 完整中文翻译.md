## 内页说明 - 文章翻译：韦伯恩：弦乐四重奏与三重奏

"四重奏演奏是最辉煌的音乐创作形式，"韦伯恩在1910年给他姐夫保罗·柯尼格的信中这样写道，回忆他在老师指导下演奏大提琴时演奏的一首作品。对勋伯格来说，四重奏也同样重要，而对韦伯恩来说也是如此。在他们合作的前两年里，除了大量的艺术歌曲外，他还创作了三部属于这里的作品：1905年在维也纳创作的慢板乐章；随后在夏季假期创作的弦乐四重奏；以及标注为1906年的一首回旋曲。一位学生、特别是勋伯格学生的习作，对我们来说现在很有趣，部分是因为这两首1905年的作品，以及在此期间完成的弦乐四重奏三首小品。

他现在最引以为豪的是两部作品：1905年的弦乐四重奏，这首韦伯恩最长的乐章，从舒伯特的先例中汲取能量，音域宽广，从韦伯恩首次全面尝试写作奏鸣曲式开头，到他三十年后创作的op.24协奏曲那样彻底。但我们必须记住，这只是他自己作品中"音乐作为声音"理念的一个记忆。最初，在1924年，他将它们组合在一起，创作了六首小曲op.9。

将1911年的乐章放在快板和韦伯恩的回旋曲之间，并压制了那首歌曲，他可能感觉到母亲的去世。另一首更悲伤的是，自从他的op.1以来，大多数作品都是如此"与他母亲有关"。另一首，更悲伤的是，在创作小曲时，他回忆道："我有种感觉，我已经说出了我要说的话，这首作品完成了。"

在1914年之后的十年里，他没有完成任何四重奏音乐（尽管他在1917-18年确实开始创作一首四重奏，当时他在军队乐团中演奏）。正如他所完成的作品是歌曲，用语言赋予它们结构。但随后勋伯格的十二音技法提供了一种方式，一旦"十二个音用完"，就可以继续创作。事实上，作曲成为了一种让十二个音在相同的线条上一次又一次用完的策略。在他最早期的序列练习中，可追溯至1924-25年，有各种钢琴、弦乐四重奏和弦乐三重奏的草图和作品，包括一首短小的、慢速的、标记为"平静流畅"的乐章（1926年夏天），保持了op.9的色调姿态和变化的色彩，但恢复了流畅的运动。终曲是脉冲式的，序列主义鼓励了准卡农式的限制，这一特征自1905年四重奏以来在他的音乐中间歇性地出现。类似的特点也持续存在于从这些研究中产生的作品中，即弦乐三重奏op.20（开始于1926年夏天，一年后完成），尽管在更广泛的两乐章跨度上。韦伯恩后来打算创作一部三乐章的作品，但他放弃了第三首回旋曲，在这部作品之前，他已经按照传统的第一乐章形式创作了慢速引子和反复的呈示部。

他接下来也是最后一部弦乐室内乐作品，四重奏op.28，是在1937年3月至1938年3月之间的一年多时间里完成的。这一次，他能够完成他的三乐章作品计划，这可以被看作是一套变奏曲，具有一些奏鸣曲式、谐谑曲和赋格曲的元素。四重奏的每个乐章都是卡农式的，每个乐章也都是B-A-C-H（降B-A-C-还原B）四音细胞变奏的延伸，这使得韦伯恩能够创造出一种自五首乐章op.5以来在他的音乐中一直很重要的赋格序列艺术，而他与奥地利阿尔卑斯山和多洛米蒂山的清晰关系给了op.28一种新的清晰度。但那些细微之处、形状、压缩、寂静的空间——一如既往地保持着。
- 保罗·格里菲斯
