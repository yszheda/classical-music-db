# 帕特里克·兰伯特 传记（英语原文中文翻译）

本CD录音可以被认为是权威性的。它们展示了20世纪最伟大指挥家之一的艺术，这是在他做出职业生涯最痛苦最重要决定——离开捷克祖国，注定永久流亡——前后不久录制的，他相信这个行动对保持他作为艺术家的人格完整至关重要。此外，这里的音乐本身也代表了这个勇敢而被围困的小国在关键历史阶段：民族奋斗（斯美塔纳和德沃夏克），独立美好时光（亚纳切克）和极权统治的悲剧（马尔蒂努）。

库贝利克的出生日期非常巧合——1914年6月29日，就在萨拉热窝刺杀事件引发一战之后一天——似乎已经预示了他一生中见证的众多政治动荡。他出生在音乐家庭，父亲是著名小提琴家扬·库贝利克。他极有天赋，记忆力惊人，拉斐尔成为全能音乐家，布拉格音乐学院毕业时同时获得作曲、小提琴和指挥学位。他还是不错的钢琴家，曾经陪伴父亲进行世界巡演。但指挥领域才是拉斐尔天赋最闪耀的地方，早年他与著名的捷克爱乐指挥瓦茨拉夫·塔利赫交往受益良多。1934年1月24日他首次指挥乐团，曲目包含他毕业作品《幻想曲》作品2，父亲担任独奏，还有柴可夫斯基第四交响曲。他后来曾说："我作为指挥学到的一切，都归功于他们。他们像怀抱婴儿一样带我成长。"

库贝利克在国际舞台的突破发生在1937年10月，他带领捷克爱乐来到英国，爱丁堡音乐节完成巡演，十分辛苦——20场音乐会加上27天内完成HMV录音——听众和评论家都完全被他们演奏的自发性征服。

第二年，慕尼黑危机之后一个月，库贝利克和"捷克斯洛伐克国家乐团"（占领后改名）再次成功巡演英国，都柏林BBC广播电台也有演出，《卫报》评论称他是战后时代最有天赋指挥之一。

纳粹保护国时期，库贝利克担任布尔诺歌剧院艺术总监，他坚持上演大胆作品，导致当局关闭了剧院。他和妻子路德米拉·贝尔特洛娃（天才小提琴家，塔利赫学生）结婚后，1942年当塔利赫离开布拉格国家歌剧院职位后，库贝利克被任命为捷克爱乐首席指挥，他成功带领乐团绕过纳粹审查。当然他节目集中安排捷克音乐；即使斯美塔纳《我的祖国》整体演出在纳粹占领下风险很高，但仍然可以在比尔森等城外演出。1945年6月20日占领结束后，二百多捷克音乐家在库贝利克指挥下在老城广场演出。

二战后新风吹来，库贝利克立即努力争取捷克爱乐的国家补贴，让乐团回到原来驻地，任命了三位捷克音乐家管理层开始新的乐章。1946年布拉格之春音乐节创办，他成为第一任总监。

到1980年代中期，糟糕的健康，尤其是难以忍受的关节炎肩痛迫使库贝利克实际上退休。天鹅绒革命后祖国恢复民主自由，奇迹般地让库贝利克重新焕发活力，他被说服重新拿起指挥棒，在1990年布拉格之春音乐节开幕音乐会上指挥"他的"捷克爱乐，象征性地为祖国自由盖章确认。

1996年8月11日库贝利克去世，他病重无法参加捷克爱乐百年庆典，捷克总统瓦茨拉夫·哈维尔给他这样的悼词："我非常钦佩拉斐尔·库贝利克，不仅因为他为捷克音乐荣耀做出一切，也因为他是非凡的人格与爱国者。"

本CD所有音乐都是库贝利克捷克曲库中核心作品，尤其是亚纳切克《小交响曲》。德国占领期间1942年1月他第一次担任捷克爱乐新任命首席订阅音乐会就指挥这部作品——考虑作品强烈爱国意义，这是大胆挑衅的选择。1946年布拉格之春音乐节闭幕音乐会之后几个月，他就录制了现在这张唱片。

库贝利克也是马尔蒂努音乐伟大拥护者。马尔蒂努是纳粹占领期间被禁的捷克流亡作曲家，解放后库贝利克立刻抓紧时间在布拉格给出第二交响曲、野场弥撒、利迪策纪念碑的首演。第五届交响曲题献给捷克爱乐，是1947年布拉格之春音乐节亮点之一。同年库贝利克邀请瑞士指挥保罗·萨谢尔指挥马尔蒂努在慕尼黑危机时题献给萨谢尔的双重协奏曲。马尔蒂努说："慕尼黑的政治展览对我来说是可怕冲击悲剧，但我认为我成功把情感放入真正经典形式。"

不知为何库贝利克从未和捷克乐团演奏德沃夏克《谐谑随想曲》，但它适合和爱乐乐团录制，因为德沃夏克1884年第一次访问英国时就是用它作为"名片"。库贝利克肯定会对爱乐首席圆号丹尼斯·布莱恩演奏满意。至于《传奇》，这是系列最后一首，用来填充原版78转唱片背面，库贝利克喜欢演奏这些被忽视作品做成完整循环。1949年2月，也就是他成为首席前一年，他在BBC广播和爱乐乐团演奏第十传奇，之后才录制了本唱片。

最后，斯美塔纳《被出卖的新娘》选段，这部歌剧是库贝利克不仅1955年在科文特花园介绍自己，更早1939年在布尔诺就已经演过。伦敦首演后，《泰晤士报》评论家写道："序曲分句迸发出乐团整晚都将流淌的活力。"

这些激动人心演奏的最终评语应该留给库贝利克自己："我努力做唱片让它们保持音乐会那种自发性。"

# 德语部分中文翻译

本CD录音可以被认为是权威性的。它们见证了20世纪最伟大指挥家之一的天才，这是在他做出最痛苦最重要决定——离开祖国永久流亡——前后录制的；只有这样他才能保持艺术完整性。此外，这里的音乐恰好代表了勇敢弱小捷克人民历史关键时刻：民族奋斗（斯美塔纳和德沃夏克），独立幸福时光（亚纳切克）和完全被占领的悲剧（马尔蒂努）。

甚至库贝利克的生日——1914年6月29日，也就是引发一战刺杀后一天——似乎已经预示了他一生中见证众多政治动荡。他出生在音乐家庭（父亲是著名小提琴家扬·库贝利克），他自己极有天赋还有惊人记忆力。他在布拉格音乐学院毕业，专业是作曲、小提琴和指挥；顺便他也是不错的钢琴家，陪伴父亲进行世界巡演。但指挥领域拉斐尔惊人天赋才能清晰显现，他和瓦茨拉夫·塔利赫——神奇捷克爱乐指挥——友谊对他帮助巨大。1934年1月24日他和乐团完成首秀；曲目包含毕业作品幻想曲作品2，父亲担任独奏。他后来曾说："我作为指挥学到一切都归功于捷克爱乐。他们像抱孩子一样带我。"

1937年10月库贝利克带领捷克爱乐来到英国完成事业突破，在岛屿巡演，27场音乐会加一次HMV录音——评论和观众都被自发性演奏迷住。

危机一个月后，也就是1938年九月慕尼黑协定之后，库贝利克带领捷克斯洛伐克国家乐团（占领后新名称）再次成功英国巡演，都柏林和BBC广播都有音乐会。《守护者》评论称他是战后时代最有天赋指挥之一。

纳粹保护国时期，库贝利克成为布尔诺歌剧院捷克艺术总监，他坚持上演如此大胆作品，导致当局关闭剧院。结婚后（妻子是天才小提琴家Ludmila Bertlová，塔利赫学生）塔利赫从布拉格歌剧院院长位置离职后，1942年库贝利克被任命为捷克爱乐首席指挥，他成功带领乐团绕过纳粹引入审查。当然他节目集中在捷克音乐；尽管整体演出斯美塔纳《我的祖国》在首都非常危险，但仍然可以在比尔森等城外演出。占领结束后，1945年6月20日二百多名布拉格音乐家在库贝利克指挥下在老城广场演出。

现在吹来完全不同风；库贝利克立刻开始为捷克爱乐争取国家补贴，让乐团回到原来位置，捷克爱乐恢复原来地位，开始三年计划，公布了俄罗斯、法国、英国、美国和犹太作曲家——那些被纳粹禁演的作曲家——作品。

为庆祝捷克爱乐成立五十周年，1946年库贝利克完成了塔利赫之后工作，把布拉格之春音乐节办成世界级。

1948年四月，库贝利克组织了外交部长扬·马萨里克纪念音乐会，扬·马萨里克在共产党政变后两周神秘死亡。节目包含约瑟夫·苏克《亚萨尔交响曲》。共产党接管后布拉格之春音乐节改名为"艺术家之家"，除了埃里希·克莱伯和卡尔韦四重奏，基本上所有客席艺术家都来自铁幕背后。挑衅地，库贝利克开场用德沃夏克交响曲。共产党接管后，他开始秘密计划移民，和扬·马萨里克秘密讨论。当爱丁堡音乐节邀请他指挥《唐璜》格林德伯恩制作，机会来了，他无法拒绝，离开国家。

慕尼黑他和妻子儿子生活了近25年。1963年他再婚，娶澳大利亚女高音埃尔西·莫里森，她在他科文特花园《被出卖的新娘》首演扮演主角玛申卡。慕尼克岁月无疑是库贝利克生活最稳定最多产时期。他继续在英国受欢迎访问演出，最著名就是1966年科文特花园《耶努发》复排。同年，德沃夏克百年诞辰，所有98位捷克爱乐成员请愿邀请他们前首席回来，苏联坦克压街后这样请愿毫无结果。

到1980年代中期，糟糕健康，尤其是难以忍受的关节炎肩膀疼痛迫使库贝利克实际上退休。天鹅绒革命后祖国恢复民主自由，奇迹般让库贝利克重新焕发，他被说服重新拿起指挥棒指挥"他的"捷克爱乐，1990年布拉格之春开幕音乐会——象征性地为祖国解放盖章。

1996年8月11日库贝利克去世，他病重无法参加捷克爱乐百年庆典，捷克总统瓦茨拉夫·哈维尔给予他这样致敬："我非常钦佩拉斐尔·库贝利克，不仅因为他为捷克音乐荣耀做一切，也因为他是非凡人格爱国者。"

本CD所有音乐都是库贝利克捷克曲库核心部分，尤其是亚纳切克《小交响曲》。德国占领1942年1月他第一次指挥捷克爱乐订阅音乐会就演它——这是大胆挑衅选择，赋予作品强烈爱国意义。占领结束后1946年布拉格之春音乐会几个月后，他就录制了这张唱片。

库贝利克也是马尔蒂努音乐伟大捍卫者。马尔蒂努是纳粹占领期间被禁的流亡捷克作曲家，解放后库贝利克立刻在布拉格安排第二交响曲、野场弥撒、利迪策纪念碑首演。第五交响曲题献给捷克爱乐，是1947年布拉格之春亮点。同年库贝利克邀请瑞士指挥保罗·萨谢尔指挥马尔蒂努在慕尼黑危机时写给他的双重协奏曲。马尔蒂努说："慕尼黑政治展览对我来说是可怕冲击悲剧，但我认为我成功把情感放入真正经典形式。"

由于未知原因库贝利克从未和捷克乐团演奏德沃夏克《谐谑随想曲》，但它适合和爱乐乐团录制，因为德沃夏克1884年第一次访问英国就把它当"名片"。库贝利克肯定对爱乐首席圆号丹尼斯·布莱恩演奏满意。至于《传奇》，这是系列最后，用来填充原版78转唱片，库贝利克喜欢演奏这些被忽视作品做成完整循环。1949年2月，也就是他成为首席前一年，他已经和爱乐乐团BBC广播演奏第十传奇，然后才录制现在唱片。

最后，斯美塔纳《被出卖的新娘》选段，库贝利克不仅1955年科文特花园用它介绍自己，更早1939年布尔诺已经用过。伦敦首演后《泰晤士报》评论家写道："序曲分句爆发出乐团整晚流淌的活力。"

这些激动人心演奏最终评语留给库贝利克自己："我努力做唱片让它们保持音乐会自发性。"
