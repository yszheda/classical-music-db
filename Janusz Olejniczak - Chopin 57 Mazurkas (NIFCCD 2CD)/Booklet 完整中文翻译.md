## 肖邦的玛祖卡舞曲

### 作者：伊雷娜·波尼亚托夫斯卡

肖邦的玛祖卡舞曲是他对波兰思念的日记。许多研究作曲家生平和作品的学者都这样描述它们。肖邦一生中都在创作玛祖卡舞曲，从他在华沙的年轻时代开始。玛祖卡的风格使他着迷，融入了他的血液，在离开波兰后，成为他与祖国和家庭的精神纽带。这种分离让他深感痛苦。1830 年圣诞节前，他在维也纳写给家人："已经过去七个星期了，我离开了你们。为什么？...我已经想念了。"他留在国外，但心情沉重。1831 年 7 月，他承认自己无法跳华尔兹："我的钢琴只听到玛祖卡"。米哈乌·克莱奥法斯·奥金斯基在他的《论音乐的书信》（1826 年）中写道，在他那个时代，玛祖卡和华尔兹的元素融合在一起，他创作了《黎明玛祖卡》和《一首华尔兹》，在德累斯顿出版。肖邦成为这两种体裁——玛祖卡和华尔兹——的最伟大大师。1845 年，在诺昂，他回到对家人的思念，与玛祖卡相关联："我总是一只脚和你们在一起，另一只脚在隔壁房间 [...] 而且完全不在自己的状态 [...] 就像往常一样，在某种奇怪的空间里"。他把这种状态称为"想象的空间"（espaces imaginaires），并补充道："我是一个失明的马佐维亚人。所以看得不远，我写了 3 首新的玛祖卡"。

作品 6 号，献给保利娜·普瓦特伯爵夫人，包括升 F 小调、升 C 小调、E 大调和降 E 小调玛祖卡。肖邦在第一首乐曲中赋予了一抹迷人的忧郁色彩，使用了旋律乐句的和声下行进行和调式音阶的运用。民间节奏在 E 大调充满活力的玛祖尔主题和降 E 小调玛祖卡中与奥贝雷克节奏结合的阴郁库亚维亚克中焕发生机。同时，升 C 小调玛祖卡的主题更多地与通俗旋律的简洁性相关联，也与引子的"舞蹈热身"有关。

作品 7 号，献给新奥尔良钢琴家保罗·埃米尔·约翰斯，包含降 B 大调、A 小调、F 小调、降 A 大调和 C 大调玛祖卡。降 B 大调玛祖尔让我们惊讶于它使用了民间利迪亚四度音程，并在第二部分的柔和库亚维亚克中，与格里索风格的增二度与低音形成不协和。A 小调玛祖卡被一种奇特折磨的情绪所渲染，主要由于半音主义。F 小调玛祖卡是一个由几个乐句组成的故事，引子基于半音和大三度的序列，这是波兰民间音乐的典型，以及库亚维亚克主题。接下来的两首玛祖卡散发出和声、设计和表达的简洁性。

作品 17 号包括降 B 大调、E 小调、降 A 大调和 A 小调玛祖卡。它献给莉娜·弗雷帕。第一首是玛祖尔类型的乐曲，第二首是忧郁的库亚维亚克，第三首沉思般地以船歌般的声音响起，第四首不仅为这套作品，也为迄今为止创作的所有玛祖卡加冕，其调性不稳定的和弦引子也为这首玛祖卡画上句号，中间部分有奥贝雷克节奏。肖普在此创造了一首具有精致和声和装饰性民间旋律的玛祖卡诗。

玛祖卡舞曲，作品 24*（G 小调、C 大调、降 A 大调、降 B 小调），献给艾米丽·德·佩尔蒂伯爵夫人。第一首（库亚维亚克）和第三首以简洁的设计和更传统的手法为标志。C 大调玛祖卡以其响亮的特点是奥贝雷克的活力；它保持了调式色彩并避免了半音记号。这是肖邦最后一次在作品中放置文字标记"自由速度"（rubato），之后他将其留给演奏者的敏感度。降 B 小调玛祖卡再次是一种精致和声写作的诗歌，带有降 D 大调的交替舞蹈次要乐句和好奇的半音下行图型。美丽的坎蒂列娜尾声带来慰藉。

玛祖卡舞曲，作品 30（C 小调、B 小调、降 D 大调、升 C 小调），献给玛丽亚·维尔滕贝格公主，呈现了对民间模式风格化的启示性新想法。第一首或许是最简单的；第二首有库亚维亚克主题，在弱和强之间坚持交替重复。第三首乐曲，降 D 大调玛祖卡，一首典型的玛祖尔，肖邦继续他的声音实验、调式波动和转调。这套作品的第四首是一首充满表达变化的精心诗歌，带有叙事曲式的引子和一个以渐隐方式消失在唤起玛祖卡节奏的经过句中的尾声。

升 G 小调、D 大调、C 大调和 B 小调玛祖卡构成作品 33*，献给罗扎·莫斯托夫斯卡。在这些作品中，肖邦回归到更传统的调性语言，无论是在第一首的库亚维亚克节奏还是在第二首旋转的乡村奥贝雷克中。简单的 C 大调玛祖卡后面是精心制作的 B 小调玛祖卡，有其重现的主题和插段。在最后一次重复主要思想之前，低音中有一个令人惊讶的 17 小节舞蹈宣叙调。

作品 41 号包括升 C 小调、E 小调、B 大调和降 A 大调玛祖卡。它献给斯特凡·维特维茨基。对于 1839 年夏天在诺昂创作的这些玛祖卡，肖邦添加了所谓的"帕尔马"E 小调玛祖卡，创作于马略卡岛，是他最美丽却最悲伤的玛祖卡之一。复杂的不协和和弦引向对半音主义不免疫的旋律和弗里吉亚音阶中的一个乐句，I 和 II 度之间有半音（肖邦在升 C 小调玛祖卡中引用了这一点）。在奥贝雷克风格的 B 大调玛祖卡中，两个八分音符和一个二分音符的"跺脚"动机打破了旋律乐句，在降 A 大调玛祖卡中，内容的同质性令人震惊，结尾处有一个中断的乐句。

40 年代玛祖卡创作的新阶段以作品 50*开始（G 大调、降 A 大调、升 C 小调玛祖卡），创作于诺昂，献给十一月起义军官莱昂·斯米特科夫斯基。G 大调玛祖卡参考了民间模式，而降 A 大调则参考了更"城市化的"库亚维亚克。同时，升 C 小调玛祖卡是一首新的玛祖卡诗歌，是该体裁中最吸引人的作品之一。女高音的动人富加尔卡（波兰民间笛子）旋律在男高音中得到模仿补充，然后是具有舞蹈效果（"跺脚"）的和弦。在中间部分（奥贝雷克），动机一遍又一遍地重复，就像在乡村舞蹈中一样。

作品 56 号（B 大调、C 大调、C 小调玛祖卡）由肖邦献给他的学生凯瑟琳·梅伯利。第一首 B 大调玛祖卡以其调性的不确定性让我们惊讶。C 大调玛祖卡是附点节奏中快速、活泼的奥贝雷克。然后这套作品再次以玛祖卡诗歌结束，首次在 C 小调中。

三首玛祖卡，作品 59* A 小调、降 A 大调和升 F 小调没有题献。半音的、不协和的模式特征是 A 小调玛祖卡。第二首乐曲，降 A 大调，是一首歌曲般的作品，但有玛祖卡节奏。在升 F 小调玛祖卡中，肖邦在升 F 大调中间部分对节奏（奥贝雷克）和旋律进行了幻想，运用了半音主义和模仿。

肖邦出版的最后一首玛祖卡作品，作品 63 号，献给劳拉·加夫罗茨卡。它包括 B 大调、F 小调和升 C 小调玛祖卡。第一首， vigorous 玛祖尔，演变成奥贝雷克，似乎在模仿对话中的歌曲。第二首，库亚维亚克类型，有一个降 A 大调中间部分带有不协和和弦。第三首，升 C 小调，以其歌唱旋律（库亚维亚克）和带有卡农式动机重复的尾声吸引听众。

接下来是两首 A 小调调性的诗意玛祖卡：一首献给埃米尔·盖拉尔，有平静的男高音和尾声。另一首为美因茨的肖特出版社的专辑，玛祖卡《我们的时代》，带有阴郁的旋律和中间部分明亮的 A 大调。

朱利安·丰塔纳死后出版的两套玛祖卡是作品 67 号：G 大调、C 小调、C 大调、A 小调；和作品 68 号：C 大调、A 小调、F 大调、F 小调。G 大调玛祖卡（作品 67 号），写入安娜·姆沃什基耶维奇的专辑，以及 C 大调和 F 大调（作品 68 号）创作于 1829-1830 年。前两首是舞曲，第三首以其对波洛奈兹形式的引用而著称。在 C 大调玛祖卡（作品 67 号）中，来自 1835 年，库亚维亚克旋律运用了半音主义，而在 A 小调（作品 67 号）中，来自 1846 年，歌曲般的旋律基于传统和声。从肖邦生命的最后时期保存下来的有 G 小调玛祖卡（作品 67 号），有其齐奏的弱音间奏曲，以及 F 小调（作品 68 号），有一个充满悲伤的精致主题。同时，A 小调玛祖卡（作品 68 号），追溯到 1827 年，显示了增四度的无情组合，用颤音强调，以及低音中的五度（e - h），产生了不协和碰撞的效果，模仿了低音提琴手与乡村音乐家的演奏。降 B 大调和 C 大调玛祖卡（1826 年在华沙出版：第 52 和 53 号）也具有增四度和增二度的民间色彩。最后的玛祖卡是 D 大调（第一版第 54 号）和降 B 大调及 C 大调第 56-58 号（这两首来自 30 年代）以及降 A 大调*（玛祖尔），来自玛丽亚·希曼诺夫斯卡的专辑，献给切利娜·米基耶维奇，1834 年。驱动这首玛祖卡开头运动的围绕降 C 音的循环图型以渐弱、很弱结束。

肖邦对民间模式进行处理的过程不是简单的风格化；它是转化，将民间元素和专业作曲技巧融合成一种综合，一种迷人的新风格，充满忧郁，但在舞蹈节奏爆发的气氛中，带有戏剧性和一丝欢乐的讽刺。古乐器的录音使我们更接近真实的声音。肖邦只曾一次表达过他对音乐中波兰风味的看法，1831 年圣诞节他写给蒂图斯·沃伊切霍夫斯基："在某种程度上 [我] 成功地感受到了我们的民族音乐"。他在作品中实现了这一点，不是"在某种程度上"，而是完全的，以高度升华的方式。

## 关于艺术家

### 亚努什·奥莱伊尼查克

亚努什·奥莱伊尼查克是当代最杰出的肖邦诠释者之一。他出生于弗罗茨瓦夫，是第八届国际弗雷德里克·肖邦钢琴比赛（1970 年）最年轻的获奖者，并在那不勒斯的阿尔弗雷多·卡塞拉国际比赛中获奖。他曾在欧洲、南北美洲、亚洲和澳大利亚演出，在最著名的音乐厅，如柏林爱乐厅、布宜诺斯艾利斯科隆剧院、普莱耶音乐厅、三得利音乐厅、林肯中心、杜塞尔多夫音乐厅和皇家音乐厅。他多次担任钢琴比赛的评委，并在欧洲、加拿大、日本和哥伦比亚举办大师班。除了古典曲目外，他还演奏波兰当代音乐（包括卢托斯瓦夫斯基、格雷茨基和基拉尔）。他曾与维托尔德·罗维茨基、安德烈·马尔科夫斯基、卡齐米日·科尔德、安东尼·维特、耶日·马克西米乌克、沃伊切赫·米赫涅夫斯基、塔德乌什·斯特乌加瓦、夏尔·迪图瓦、安杰伊·博雷伊科、格热戈日·诺瓦克和雅切克·卡斯普日克等指挥家合作指挥的乐团演出。多年来，他还与马雷克·莫什和奥克索乐团合作。他是最早在古乐器上演奏肖邦音乐的演奏家之一，是华沙"肖邦和他的欧洲"音乐节的常客，包括与弗兰斯·布鲁根指挥的十八世纪乐团和菲利普·赫雷韦赫指挥的香榭丽舍乐团的合作。他录制了超过 40 张唱片，包括为弗雷德里克·肖邦研究所录制的多张唱片，以及罗曼·波兰斯基的《钢琴家》和安德烈·祖瓦夫斯基的《蓝色音符》的电影原声带。他曾被授予波兰复兴骑士十字勋章（2000 年）、"艺术荣耀"金奖章（2005 年）和"弗雷德里克"奖（八次）。自 2015 年以来，亚努什·奥莱伊尼查克与华沙弗雷德里克·肖邦音乐大学定期合作。

## 埃拉德钢琴 [1849]

这件乐器于 1849 年在巴黎制造。标有序列号 21118，其结构与弗雷德里克·肖邦熟悉的乐器相同。其金属框架包括一个挂弦销钉板（琴弦拉伸在挂弦销钉板和弦轴销钉板之间）和六个支撑架（平衡紧绷琴弦的合力，达到 20 吨）。它是当今使用的铸铁钢琴框架的前身。键盘覆盖总共 7 1/4 个八度，如同现代音乐会三角钢琴。乐器的原始历史物质完整保存，除了因使用而常规更换的元件。修复时使用了相同的元件，由相同的原材料和与 19 世纪中期相同的技术制造。这架钢琴是雷沙德·克劳泽基金会赠送给弗雷德里克·肖邦研究所的礼物。
