## 约尔格·维德曼的钢琴作品
### 马库斯·费恩采访约尔格·维德曼

让我们首先谈谈这张 CD 上最早的钢琴作品《恶之花》(1996/97)。您并不是以一种宁静、带着其沉重传统、非常试探性的方式接近钢琴的；在我看来，您从一开始就全力以赴，有意识地探索极端的音乐界限——钢琴被带入一些危险的阈值区域。

《恶之花》当然是一种危险形式，它依靠钢琴家无拘无束的强度而生。在这首作品中，耳朵必须非常敏捷，因为音乐的行为经常突然改变：一瞬间是点彩派的突然闪光，下一秒是闪烁的织体。然而，这种声音想法的多样性被严格的形式所约束。

在副标题中，您将《恶之花》称为"依波德莱尔的钢琴奏鸣曲"...

...正是因为我对一种特定的张力区域着迷：波德莱尔，这位谵妄和远见的大师，以典范的古典形式——奏鸣曲式——书写他的文本。这种极性正好反映在我的作品中。当然，当时我也对波德莱尔《恶之花》的基本美学焦点感兴趣：邪恶中的美。我不得不反复阅读这些诗歌——部分是因为我在这些文本中认出了自己。将这些文学中有毒、绿色的烟雾转化为钢琴声音是一个巨大的挑战；钢琴最初似乎太过具体，无法唤起这种飘浮、模糊的品质。

您在《恶之花》中引用了波德莱尔的个别诗歌吗？

在一个重要的地方，我引用了诗歌《相册》的第一行。歌词写在乐谱中，但应该由钢琴家默念："Souvent pour s'amuser"（常常为了消遣）。这里的音乐节奏直接源自波德莱尔的段落，但这在作品中是个例外。除此之外，我试图更普遍地捕捉波德莱尔语言的特殊声音。在《相册》这首诗中，他描述了水手的恶意，他们捕捉信天翁为了自娱自乐并折磨它们。最终，这首诗是艺术家存在的隐喻，波德莱尔将信天翁比作诗人。我的《恶之花》就是关于这个的：有人在飞翔。但不了多久了。

这让我来到 2007 年的《十一首幽默曲》，因为这些作品也描述了一种坠落、崩溃。最后一个乐章"幽默与细腻"开始得细腻而富有诗意，带有遥远的声音，仿佛是从磨砂玻璃后面传来的。一层忧郁的面纱笼罩着这首音乐——直到它被撕开，音乐突然坠入深渊。

是的，在这首作品中有些东西被打破了——一个被毁坏的音乐盒，一个生病的钟琴。但坠落在这个乐章中早已开始：一个音符悬而未决，音乐无处可去，音乐变得模糊... 在我看来，音乐以某种形式的灾难结束是不可避免的。

您能谈谈其他乐章吗？

它们是性格乐章，与罗伯特·舒曼的《性格曲》非常一致，《十一首幽默曲》无疑参考了这一点。在这些幽默曲中，我以我自己的方式追溯舒曼的姿态：在第三乐章"开始时活泼"中，那种狂热而紧张的舒曼式情绪，虽然在乐章过程中逐渐被抑制。《梦中的歌》是对舒曼《幽灵变奏曲》的反思——虽然短暂，但是一部非常冒险的音乐作品。高音 A 与原本的降 E 大调发生激烈冲突。在他生命的最后一年，舒曼听到了 A 音上的耳鸣。这一定折磨着他——在一首降 E 大调的作品中！但这段段落是我能想到的唯一真正的引用。我对向舒曼的听觉致敬不感兴趣。

我总的印象是，您创作了一部音乐，它使用"幽默曲"的伪装，也许也在舒曼的掩护下，触及了非常严肃和非常个人的主题。

我很高兴你这样听音乐。你看，即使在舒曼的作品中也有引用或直接参考；任何人都可以说，"啊，这里是引用！"这很好，但为什么舒曼引用那个特定的部分？它在整体戏剧结构中出现在哪里？他是什么意思？他的个人情况是什么？我对这个第二层次感兴趣。

让我们回到 2001 年，回到短短约 90 秒的《C 大调片段》...

...我把它献给我的前作曲老师维尔弗里德·希勒的 60 岁生日。我能用 C 音、用 C 大调和弦做什么？这正是我和维尔弗里德·希勒思考的问题。他教会我省略音符。《C 大调片段》就是受此启发。它实际上是一个基于 C 音的泛音作品，有一些与 C 大调相结合的非常奇怪的和弦。我喜欢这首作品的是它开放、陌生的品质——所有这些都从一个简单的 C 和弦发展而来。

这首作品以钢琴机身上有力的敲击开始，这在回声室中持续。这是您在次年创作的《托卡塔》中的重要原则。

没错。攻击——衰减。这两个层面在作曲上以多种变体精心制作。自然，攻击的戏剧性形式最能打动听众，即钢琴家的"toccare"：快速重复、和弦敲击，更不用说敲击钢琴盖了。但我希望人们也能聆听共鸣。

这部作品是为 ARD 国际音乐比赛委托创作的。

它引发了观众的激烈反应。我记得获奖者伊琳娜·鲁索走上舞台，仿佛她要去执行死刑。就好像饥饿的狮子坐在那里，将声音投掷出来——甚至鞭打它——从钢琴中。慕尼黑赫库勒萨勒的气氛非常紧张。

《光的研究 III》是不久之后创作的，但它具有完全不同的特征。对我来说，这是一首内省、压抑的作品。

当时我正在寻找一种不同的表达理想，我从视觉艺术中汲取灵感并非巧合，在这种情况下是詹姆斯·特瑞尔的灯光和声音装置。在寻求不同美学的过程中，《光的研究 III》是一部极端的作品。它是纯粹形式的游戏，是光影效果的研究，也是和弦的研究，和弦根据过滤原则逐个音符地减少。经过一段时间后，人们最希望的是某种解放的爆发或对比。但这首作品坚持一个单一的想法并保持静止；因此它的难以接近的氛围。《光的研究 III》将听众带入压抑的空间——但也使一种新的、晶体般的聆听方式成为可能。人们之后会以不同的方式聆听事物。至少，这就是我的目标。

*德文翻译：Wieland Hoban*

## 约尔格·维德曼

**约尔格·维德曼 (JÖRG WIDMANN)**，1973 年生于慕尼黑，在家乡的音乐学院师从格尔德·斯塔克学习单簧管，后来在纽约茱莉亚音乐学院师从查尔斯·尼迪奇。他十一岁开始学习作曲，老师包括维尔弗里德·希勒、汉斯·维尔纳·亨策、海纳·格贝尔斯和沃尔夫冈·里姆。

作为单簧管演奏家，维德曼最大的热情是室内乐。他经常与塔贝亚·齐默尔曼、海因茨·霍利格、安德拉斯·席夫、克里斯蒂安·特兹拉夫和吉顿·克莱默等合作伙伴演出。作为协奏曲独奏家，他在国内外也取得了成功（曾与莱比锡格万豪斯管弦乐团、柏林 DSO、巴伐利亚广播交响乐团、皇家爱乐乐团、爱尔兰室内乐团等合作），与克里斯托夫·冯·多赫南伊、西尔万·康布雷林、克里斯托夫·艾森巴赫、大卫·津曼和长野健等指挥家合作。多部新的单簧管协奏曲是专门为他创作的，包括沃尔夫冈·里姆、阿里伯特·赖曼和海因茨·霍利格的作品。约尔格·维德曼曾在各个音乐节和机构担任驻场作曲家和艺术家，包括萨尔茨堡音乐节、卢塞恩音乐节、科隆爱乐厅、维也纳音乐厅，以及 2010/11 年与克利夫兰乐团。自 2001 年以来，他一直担任弗莱堡音乐学院的钢琴教授，2009 年还成为作曲教授。他的作品获得了众多国家和国际奖项。

## 扬·菲利普·舒尔策

**扬·菲利普·舒尔策 (JAN PHILIP SCHULZE)** 是一位多面手独奏家、声乐伴奏和当代音乐专家，曾在最重要的国际场馆演出，合作过的伙伴包括朱莉安·班瑟、安妮特·达施、迪特里希·亨舍尔、乔纳斯·考夫曼、罗伯特·迪恩·史密斯和维奥莱塔·乌尔马纳。他与汉斯·维尔纳·亨策、沃尔夫冈·里姆、迪特·施内贝尔和约尔格·维德曼等作曲家密切合作，并曾与慕尼黑爱乐乐团以及巴伐利亚和西德广播交响乐团同台演出。他是汉诺威音乐戏剧学院的艺术歌曲教授，并为亨乐和布莱特科普夫音乐出版社工作。
