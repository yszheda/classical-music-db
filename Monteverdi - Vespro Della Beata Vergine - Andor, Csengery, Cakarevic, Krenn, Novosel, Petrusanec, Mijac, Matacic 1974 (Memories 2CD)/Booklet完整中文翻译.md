## 第六页

**克劳迪奥·蒙特威尔第**
**《圣母晚祷》**

1960年9月，威尼斯的里卡尔多·阿马迪诺出版了蒙特威尔第这部最令人印象深刻的作品，献给教会使用。

> **至圣 / 圣女 / 弥撒与六声部 / 为教堂合唱 / 多首晚祷 / 搭配多首 / 圣乐协奏曲 / 适合小堂或私人祈祷室 / 克劳迪奥·蒙特威尔第作曲 / 新近完成 / 献给 / 教宗保罗五世**

这部作品分为三个部分。它包含一部弥撒（"in illo tempore"弥撒，为六声部而作），创作于古典复调声乐风格，这种风格在罗马大教堂仍然流行；五篇诗篇、一首赞美诗和《尊主颂》，为"圣母圣诞共同节庆"的晚祷而作，采用协奏风格创作，为六、七、八和十声部，加上管风琴和乐器，特别适合资源丰富的圣堂；还有多首《圣协奏曲》，为单声部或少量声部而作，用管风琴，只有《圣母奏鸣曲》使用乐器，这些作品只需要有限数量的演奏者就能演出。

在阿马迪诺的版本中，作品按以下顺序印刷：无伴奏弥撒基于贡贝蒂的经文歌"in illo tempore" → 《上帝，请帮助我》六声部 → 《我虽然黑》独唱 → 《少年人哪，你们要赞美耶和华》八声部 → 《你甚美丽》二声部 → 《我素来欢喜》六声部 → 《两个撒拉弗》三声部 → 《若不是耶和华》十声部 → 《请听，诸天》六声部 → 《耶路撒冷赞美》七声部 → 《圣母奏鸣曲》八声部 → 《海星圣母》八声部 → 《尊主颂》七声部 → 《尊主颂》六声部。

**八声部 - 《尊主颂》七声部 - 《尊主颂》六声部**

（扉页不是特别清晰）扉页和作品顺序可能会让我们认为，除了弥撒之外，所有作品都属于晚祷。礼仪上来说，只有《上帝，请帮助我》、五首诗篇、《海星圣母》赞美诗和《尊主颂》属于晚祷，其他作品被标记为《圣协奏曲》，它们不属于晚祷，特别是《我虽然黑》《你甚美丽》《两个撒拉弗》《请听，诸天》《圣母奏鸣曲》。

确实属于晚祷的作品都基于固定歌调（cantus firmus），也就是分别以诗篇、赞美诗和尊主颂的格列高利素歌旋律为基础。其他作品不基于固定歌调，只有《圣母奏鸣曲》例外，它基于连祷旋律。

在晚祷中，固定歌调部分非常清晰突出；几乎总是由男高音声部担任，偶尔会从一个声部转到另一个声部。

蒙特威尔第使用彼此密切关联的主题，几乎总是保持在原有的格列高利素歌形态中，他在构建宏大结构时创造了奇迹，使用大胆技法来变化节奏模式，并在形式与结构上创造出庄严感。

**洛夫罗·马塔契奇**

克罗地亚指挥家与作曲家洛夫罗·冯·马塔契奇（1899年2月14日生于苏沙克，1985年1月4日逝世于萨格勒布）属于20世纪欧洲和世界音乐精英。他在传统与文化的交汇处完成了个人与艺术教育，他成功地融合与综合了各种差异。他的音乐教育始于维也纳音乐学院（I.赫布斯特，O.内德巴尔），他的职业生涯在科隆、奥西耶克、卢布尔雅那和萨格勒布开始成型，并在第二次世界大战后达到顶峰。

他一直是慕尼黑和维也纳歌剧院的常客；后来他成为德累斯顿国家乐团与歌剧院、东柏林歌剧院（1956-58）的首席指挥，然后是法兰克福歌剧院院长（1961-65），日本放送协会（NHK，日本广播电视交响乐团）荣誉终身首席指挥（自1965年起），萨格勒布爱乐乐团荣誉终身指挥（自1970年起），摩纳哥国家乐团荣誉指挥（1964-70）。

同时他也与柏林爱乐、维也纳爱乐、伦敦爱乐、捷克爱乐以及许多美国乐团合作演出。他曾担任罗马歌剧院、米兰斯卡拉歌剧院、拜罗伊特以及许多其他歌剧院的指挥。尽管他创作的作品数量不多，但其创作作品散发出非凡的表现力。他传奇的诠释（特别是布鲁克纳和瓦格纳，以及斯拉夫曲目）赢得了最高认可：国际布鲁克纳协会布鲁克纳奖章，维也纳爱乐布鲁克纳指环，捷克政府颁发的亚纳切克和斯美塔那奖章，奥地利总统颁发的一等艺术与科学十字勋章，柏林爱乐汉斯·冯·比洛奖章，以及许多其他奖项。

马塔契奇诠释的非凡力量源于他将宏伟形式与表现力乐句融为一体，也源于他对所有作品全面深入的了解，丰富细节在稳固概念架构内自然脉动。

## 第七页

**洛弗罗与莉莉·马塔契奇基金会**

洛弗罗与莉莉·马塔契奇基金会成立于1987年，旨在推广克罗地亚国内外优秀青年指挥家的卓越成就。这是一个公民基金会，它在两个层面实现目标：向一定数量的候选人和学生提供年度奖学金，以及每四年举办一次全面的国际青年指挥比赛。

前者包括财务和其他形式对青年指挥家专业发展的支持，基于专家评审团的决定。

迄今为止，基金会已经支持了许多天才克罗地亚青年指挥家，为他们提供奖学金和其他个人形式的帮助，帮助他们开启职业生涯。

作为洛弗罗·马塔契奇青年指挥比赛的组织者，基金会旨在为青年指挥提供更广阔发展空间。这个国际项目的声誉和影响力应该已经提升了艺术家洛弗罗·马塔契奇在当今音乐界已经很高的地位。同时，连同基金会的文献整理和推广活动，这个项目应该能保证洛弗罗·马塔契奇知识遗产的延续性和生命力。

**克劳迪奥·蒙特威尔第**
**《圣母晚祷》**

（克罗地亚语原文，翻译如下）

1960年9月，威尼斯出版商里卡尔多·阿马迪诺出版了蒙特威尔第最重要的作品，供教会使用。

> **至圣 / 圣女 / 弥撒与六声部 / 为教堂合唱 / 多首晚祷 / 搭配多首 / 圣乐协奏曲 / 适合小堂或私人祈祷室 / 克劳迪奥·蒙特威尔第作曲 / 新近完成 / 献给 / 教宗保罗五世**

作品分为三个部分。它包含一部弥撒（"in illo tempore"弥撒），创作于古典复调声乐风格，这种风格在罗马大教堂仍然常见；五篇诗篇、一首赞美诗和《尊主颂》，为"圣母圣诞共同节庆"的晚祷而作，采用协奏风格创作，为六、七、八和十声部，加上管风琴和乐器，特别适合资源丰富的圣堂；还有几首《圣协奏曲》，为一个或几个声部，用管风琴（只有《圣母奏鸣曲》用乐器），它们可以用数量有限的乐器演奏。

阿马迪诺出版的作品按以下顺序排列：无伴奏弥撒六声部，基于贡贝蒂的经文歌"In illo tempore" → 《上帝，请帮助我》六声部 → 《我虽然黑》独唱 → 《少年人哪，你们要赞美耶和华》八声部 → 《你甚美丽》二声部 → 《我素来欢喜》六声部 → 《两个撒拉弗》三声部 → 《若不是耶和华》十声部 → 《请听，诸天》六声部 → 《耶路撒冷赞美》七声部 → 《圣母奏鸣曲》八声部 → 《海星圣母》八声部 → 《尊主颂》七声部 → 《尊主颂》六声部。

不清晰的引言部分和作品顺序可能会让人以为，除了弥撒之外，所有其他作品都属于晚祷。礼仪上，只有《上帝，请帮助我》、五首诗篇、《海星圣母》赞美诗和《尊主颂》属于晚祷，其他标注为《圣协奏曲》的作品不属于，也就是《我虽然黑》《你甚美丽》《两个撒拉弗》《请听，诸天》《圣母奏鸣曲》。除了那些礼仪上属于晚祷的作品，所有其他作品都基于固定歌调，也就是对应诗篇、赞美诗和尊主颂的格列高利素歌旋律。

其他作品不基于固定歌调，除了基于连祷旋律的《圣母奏鸣曲》。固定歌调在晚祷中非常清晰，几乎总是交给男高音，偶尔也会由其他声部演奏。

奇妙的是，蒙特威尔第使用保持几乎原创格列高利素歌的相关主题，清晰地构建出宏大结构，大胆使用不同节奏模式技巧，创造出宏伟形式和结构。

## 第八页

**洛夫罗·马塔契奇**

（克罗地亚语原文，翻译如下）

克罗地亚指挥家和作曲家洛夫罗·马塔契奇（1899年2月14日生于苏沙克 - 1985年1月4日逝世于萨格勒布）属于二十世纪欧洲和世界音乐精英。他在传统和文化交界处完成人文和艺术成型，他令人惊讶地成功吸收和综合了不同传统带来的差异，将它们融入到他丰富表达和理解中。他在维也纳音乐学院学习（I.赫布斯特，O.内德巴尔），职业生涯在科隆、奥西耶克、卢布尔雅那和萨格勒布开始，第二次世界大战后达到顶峰。

他一直是慕尼黑和柏林歌剧院的客座指挥，然后成为德累斯顿国家歌剧院和东柏林歌剧院（1956-58）首席指挥，法兰克福歌剧院院长（1961-65），日本NHK交响乐团荣誉首席指挥（自1965年），萨格勒布爱乐乐团（自1970年）和摩纳哥国家乐团（1964-70）荣誉指挥。同时他还在柏林、维也纳、伦敦、捷克爱乐和许多美国乐团指挥。他在罗马歌剧院、米兰斯卡拉、拜罗伊特和许多其他歌剧院担任指挥。尽管他作品数量不多，但充满表达财富。

他对布鲁克纳和瓦格纳作品，以及斯拉夫曲目的经典诠释为他赢得了许多认可：国际布鲁克纳协会布鲁克纳奖章，维也纳爱乐布鲁克纳指环，捷克斯洛伐克政府亚纳切克和斯美塔那奖章，奥地利共和国总统一级艺术科学十字勋章，柏林爱乐汉斯·冯·比洛奖章等等许多奖项。

马塔契奇诠释特别力量在于他将宏伟形式和丰富表现力乐句结合，在坚实概念架构内，丰富细节自然地焕发生命。

**洛弗罗与莉莉·马塔契奇基金会**

洛弗罗与莉莉·马塔契奇基金会成立于1987年，根据遗嘱创始人夫妇意愿建立，目的是促进克罗地亚国内外特别有天赋青年指挥发展。基金会作为公民协会成立，其基本任务在两个层面实现：每年向一定数量候选人和学生提供奖学金，以及每四年举办一次全面的国际青年指挥比赛。在第一种情况下，基于先前文件和专家评审团决定，选出的候选人和学生获得金钱和其他形式帮助，用于专业发展和进步，这种赞助可以持续较长时间。

就这意义而言，基金会迄今为止鼓励和资助了许多来自我国的天才青年指挥开始职业生涯。作为洛弗罗·马塔契奇青年指挥比赛组织者，基金会希望为年轻指挥家发展提供更广阔空间，这个项目让洛弗罗·马塔契奇这个名字在当今音乐世界获得更高国际地位，同时，连同文献整理和推广活动，基金会保证洛弗罗·马塔契奇知识遗产延续性和生命力。

**克劳迪奥·蒙特威尔第**
**《圣母晚祷》**

（意大利语原文，翻译如下）

1960年9月，威尼斯出版商里卡尔多·阿马迪诺出版了蒙特威尔第献给教会使用的最恢宏作品。

> **至圣 / 圣女 / 弥撒与六声部 / 为教堂合唱 / 多首晚祷 / 搭配多首 / 圣乐协奏曲 / 适合小堂或私人祈祷室 / 克劳迪奥·蒙特威尔第作曲 / 新近完成 / 献给 / 教宗保罗五世**

作品分为三个部分。包含一部弥撒（"in illo tempore"弥撒，为六声部），创作于经典复调声乐风格，这种风格在罗马大教堂仍然流行；五首诗篇，赞美诗和《尊主颂》，为"圣母圣诞共同节庆"晚祷，协奏风格创作，为六、七、八和十声部，管风琴和乐器，特别适合资源丰富的圣堂；一些《圣协奏曲》，给一个或几个声部，管风琴伴奏，只有《圣母奏鸣曲》用乐器，可以用有限数量乐器演奏。

在阿马迪诺版本中，作品按以下顺序呈现：无伴奏弥撒六声部，基于贡贝蒂的经文歌"In illo tempore" → 《上帝，请帮助我》六声部 → 《我虽然黑》独唱 → 《少年人哪，你们要赞美耶和华》八声部 → 《你甚美丽》二声部 → 《我素来欢喜》六声部 → 《两个撒拉弗》三声部 → 《若不是耶和华》十声部 → 《请听，诸天》六声部 → 《耶路撒冷赞美》七声部 → 《圣母奏鸣曲》八声部 → 《海星圣母》八声部 → 《尊主颂》七声部 → 《尊主颂》六声部。

扉页不是很清晰，作品顺序可能会让人认为，除去弥撒，所有其他作品都属于晚祷。礼仪上，只有《上帝，请帮助我》和五首诗篇，《海星圣母》赞美诗和《尊主颂》属于晚祷，剩下作品包括这些《圣协奏曲》，特别是《我虽然黑》《你甚美丽》《两个撒拉弗》《请听，诸天》《圣母奏鸣曲》不属于晚祷。此外，属于晚祷的作品都建立在固定歌调上，也就是对应诗篇、赞美诗和尊主颂的格列高利素歌旋律。

其他作品不建立在固定歌调上，除了《圣母奏鸣曲》建立在连祷旋律上。固定歌调在晚祷中非常突出，几乎总是交给男高音，偶尔也会在不同声部之间流动。

蒙特威尔第令人惊叹，在保持几乎原创格列高利素歌的相关主题上，能够清晰地构建出宏伟结构，大胆技法处理各种节奏型，在形式和结构上创造出庄严。

## 第九页

**洛夫罗·马塔契奇**

（意大利语原文，翻译如下）

克罗地亚指挥家和作曲家洛夫罗·冯·马塔契奇（1899年2月14日，苏沙克 - 1985年1月4日，萨格勒布）属于本世纪欧洲和世界音乐精英。他在传统与文化十字路口完成个人和艺术成长，他成功地典范吸收和综合了各种多样性。他在维也纳音乐学院接受音乐教育（I.赫布斯特，O.内德巴尔），职业生涯在科隆、奥西耶克、卢布尔雅那和萨格勒布开始成型，第二次世界大战后达到顶峰。

他一直是慕尼黑和维也纳歌剧院客座指挥，随后成为德累斯顿国立歌剧院与乐团、东柏林歌剧院（1956-58）首席指挥，法兰克福歌剧院（1961-65）首席指挥，日本放送协会（NHK，日本广播电视交响乐团）荣誉首席指挥（自1965年），萨格勒布爱乐乐团（自1970年）荣誉首席指挥，摩纳哥国家乐团（1964-70）指挥。同时他也与柏林爱乐、维也纳爱乐、伦敦爱乐、捷克爱乐以及许多美国乐团合作。他曾担任罗马歌剧院、米兰斯卡拉歌剧院、拜罗伊特以及许多其他歌剧院指挥。

尽管他创作作品份量不多，但散发出非凡表现力。他传奇的诠释（布鲁克纳、瓦格纳，特别是斯拉夫曲目）赢得了最高认可：国际布鲁克纳协会布鲁克纳奖章，维也纳爱乐布鲁克纳指环，维也纳爱乐的亚纳切克和斯美塔那奖章，奥地利总统颁发的一等艺术科学十字勋章，柏林爱乐汉斯·冯·比洛奖章，以及许多其他奖项。

马塔契奇诠释非凡力量源于宏伟形式与表情乐句融合，也源于他对指挥每部歌剧深刻知识，细节在稳固结构框架内。

**洛弗罗与莉莉·马塔契奇基金会**

洛弗罗与莉莉·马塔契奇基金会1987年成立，旨在推广克罗地亚国内外天才青年指挥家成就。它是一个公民基金会，其工作分为两个层面：每年为一定数量候选人和学生提供奖学金，以及重要的国际青年指挥比赛每四年举办一次。前者包括经济援助和其他形式支持，帮助青年指挥专业发展和进步，由专家评审团决定。

迄今为止，基金会已经支持了许多克罗地亚天才青年，为他们提供研究金和其他个人化形式帮助，开启他们职业生涯。

作为洛弗罗·马塔契奇青年指挥比赛组织者，基金会寻求为青年指挥提供更广阔领域。这个项目的声誉和影响力在国际上应该进一步提升艺术家洛弗罗·马塔契奇在当代音乐界已经尊贵的名字。同时，连同文献和推广活动，这个项目应该保证洛夫罗·马塔契奇知识遗产延续性和生命力。
