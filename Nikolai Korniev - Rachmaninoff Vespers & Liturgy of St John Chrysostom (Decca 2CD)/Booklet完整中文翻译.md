## 内页介绍文章（翻译）

拉赫玛尼诺夫对教堂曲目做出了杰出贡献，也带来一个风格恰当性问题：他的教会音乐一直被指责过度复杂。（难怪他的《晚祷》在西方已经成为音乐会"保留曲目"。）作为作曲家，他受到柴可夫斯基鼓励，俄罗斯正教曲目复兴运动也进一步促进他创作，这场复兴当时正发生在俄罗斯教会音乐领域。就此而言，他十五年后创作的《晚祷》无疑更宏伟、织体更丰富，而更早创作的《圣约翰·克里索斯托礼仪》则是柴可夫斯基开创性工作当之无愧继承者，和前作一样，文本能够唤起真挚情感，作曲家情感灵敏度并未完全被教会束缚。《晚祷》包含十五个乐章，其中九个使用古老圣咏，它很可能是当前选集中王冠上的明珠，它"合唱配器"在彻夜 vigil 歌剧般强度暗夜中发光。

拉赫玛尼诺夫对宗教曲目的杰出贡献，引出风格恰当性问题，他的教会音乐一直被指责过度精心创作。（难怪他的《晚祷》在西方已经成为音乐会固定曲目。）作为作曲家，他受到柴可夫斯基鼓励，拉赫玛尼诺夫进一步受到俄罗斯东正教正典复兴运动刺激，这场复兴当时发生在俄罗斯教会音乐界。在这方面，他1910年《礼仪》特别受到作曲家/音乐学家/合唱指挥亚历山大·卡斯塔尔斯基（1856-1926）影响，拉赫玛尼诺夫创作期间向他寻求建议。尽管《晚祷》晚五年创作毫无疑问更宏伟，织体也更丰富，《礼仪》仍然是柴可夫斯基开拓性工作当之无愧合格继承者，和前作一样，作品闪耀着同样真诚情感，这种情感是文本能够唤起，而这种敏感度并不完全受教会束缚。《晚祷》十五个乐章（九个使用古代圣咏）很可能就是当前选集中最美花朵，它"合唱配器"在彻夜 vigil 完整强度黑暗中闪闪发光。

拉赫玛尼诺夫对教会曲目的伟大贡献提出了风格恰当性问题，即他的音乐是否适合教堂使用，他的音乐被指责过度精心雕琢。（难怪他的《晚祷》在西方已经成为音乐厅"公众宠儿"。）作为作曲家，他受到柴可夫斯基鼓励，拉赫玛尼诺夫在俄罗斯正统曲目创作贡献进一步受到俄罗斯教会音乐学术复兴努力推动。从这个角度看，他的《晚祷》（1910）特别是对作曲家/音乐学家亚历山大·卡斯塔尔斯基（1856-1926）工作感谢，卡斯塔尔斯基对他研究俄罗斯教会音乐给予帮助。

《晚祷》十五个乐章改编（九个基于古老圣咏），它很可能就是本选集中王冠宝石，它"合唱配器"在漫漫长夜 vigil 散发出明显强度光辉。

## CD 1 - 晚祷 作品37（彻夜祈祷）

### 1. 来吧，让我们跪拜
**教会斯拉夫语原文** 译文见上文英文，中文译文：
```
阿门。
来吧，让我们跪拜我们的君王上帝。
来吧，让我们跪拜俯伏在基督面前，我们的君王上帝。
来吧，让我们跪拜俯伏在基督我们的君王上帝面前。阿门。
```

### 2. 我的灵魂啊，你要赞美主
```
阿门。
我的灵魂啊，你要赞美主。你有福了，主啊，我的上帝。你非常伟大，你有福了，主啊。你披上荣耀和威严，你有福了，主啊。你的作为何其伟大，主啊。水中山峰矗立，你的作为何其伟大，主啊。荣耀归于你，主啊，你创造了万物。阿门。
```

### 3. 那人有福了
```
那不走恶人计谋的人有福了。哈利路亚。因为主知道义人的道路，恶人的道路必灭亡。
```

### 4. 哦，宁静之光
```
（晚祷赞美诗）
哦耶稣基督，神圣不朽天父荣耀的温柔之光，我们日落之后来到这里，我们现在歌唱赞美上帝圣父、圣子、圣灵。在任何时刻配得受一切生灵赞美，圣子上帝，赐予生命者，因此全世界赞美你。
```

### 5. 主啊，如今你释放仆人
```
（基万旋律）
主啊，如今按照你的话释放你的仆人，你让我眼睛看见你救恩，就是你预备在万民面前预备救恩，光照外邦人，作你民以色列荣耀。
```

### 6. 上帝之母 圣女
```
（Troparion）
上帝之母圣女你有福了，恩典充满玛利亚，主与你同在。你在妇女中受称颂，你腹中胎儿你受称颂，你生下我们灵魂救主。
```

### 7. 荣耀归于至高上帝
```
荣耀归于至高上帝，在地平安，恩惠归于世人。我们赞美你，我们祝福你，我们崇拜你，我们荣耀你，我们为你的大能感谢你，荣耀天国君王天父。
```

### 8. 赞美主名
```
（赞美诗）
赞美主名，哈利路亚。赞美仆人主，哈利路亚。主从锡安有福，他住在耶路撒冷，哈利路亚。感谢主，因为他本为善，他慈爱永远，哈利路亚。哈利路亚。
```

### 9. 愿你得福，主啊
```
（祝福）
愿你得福，主啊，用你的律法教训我。
天使盛会惊讶，看见你死在十字架，救主啊，你打破死亡权势，亚当赎了罪，将我们从死亡救出。愿你得福，主啊，用你的律法教训我。
```

### 10. 我们看见了基督复活
```
我们看见了基督复活，让我们崇拜圣洁主耶稣，唯一无罪救主。我们崇拜你十字架，我们崇拜你神圣复活，拯救我们，主啊。
```

### 11. 我灵魂尊主为大
```
我灵魂尊主为大，我灵在上帝我救主里面欢乐。
比基路伯更尊贵，比撒拉弗更荣耀，你无罪生下上帝之道，我们真福之母上帝之母，我们将你 magnify。他对我这个卑微婢女施行了大事，他圣名可敬。他怜悯从一代到一代敬畏他人。
比基路伯更尊贵，比撒拉弗更荣耀，你无罪生下上帝之道，我们真福之母上帝之母，我们将你 magnify。阿门。
```

### 12. 荣耀归于至高上帝
```
（大 doxology）
荣耀归于至高上帝，在地平安，恩惠归于世人。我们赞美你，我们祝福你，我们崇拜你，我们荣耀你，我们为你的大能感谢你，天父全能君王。祝福每一个灵魂每一个灵。荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。
```

### 13. 今日救恩降临
```
（复活 Troparion 一）
今日救恩降临世界，从坟墓复活，成为我们生命元首。他以死亡毁灭死亡，赐给我们胜利和永生。救我们，上帝儿子，从死复活主。
```

### 14. 从坟墓复活
```
（复活 Troparion 二）
你从坟墓复活，打破地狱枷锁，你毁灭了死亡判决，主啊，你向全世界宣讲第二次诞生。
```

### 15. 给你，战斗领袖
```
（Kontakion）
给你，上帝之母，我们战斗领袖胜利者，我们你的仆人唱出胜利，你从一切灾难中将我们救出，你赐我们力量战胜敌人，欢喜吧，未婚新妇。
```

## CD 2 - 圣约翰·克里索斯托礼仪 作品31

### 1. 第一对经
```
我的灵魂啊，你要赞美主，我里面一切都要赞美圣名。我的灵魂啊，你要赞美主，不要忘记他一切恩惠。他赦免你一切罪孽，他救赎你生命脱离死亡，他以慈爱和怜悯冠冕你。满足你愿望美好事物，你少年人更新如鹰。阿门。

荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。
```

### 2. 第二对经
```
荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。

独生子上帝之道，虽然不朽，你为了我们救恩乐意降世成人，从圣灵感孕，由童贞女玛利亚肉身成形，没有改变神性，成为人，被钉十字架，复活升天，坐在天父右边，他还要再来荣耀审判活人死人，他国度没有穷尽。
荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。
```

### 3. 第三对经
```
你的国降临的时候，主啊，求你在你国中记念我们。
虚心的人有福了，因为天国是他们的。哀恸的人有福了，因为他们必得安慰。饥渴慕义的人有福了，因为他们必得饱足。怜恤人的人有福了，因为他们必蒙怜恤。清心的人有福了，因为他们必得见上帝。使人和睦的人有福了，因为他们必称为上帝儿子。为义受逼迫的人有福了，因为天国是他们的。人若因我辱骂你们逼迫你们捏造各样坏话毁谤你们，你们就有福了。应当欢喜快乐，因为你们在天上赏赐大。

荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。
```

### 4. 小入口
```
智慧！请留心！
来吧，让我们跪拜俯伏在基督面前。拯救我们，上帝儿子，从死复活那位。哈利路亚。
```

### 5. 三圣哉经
```
圣上帝，圣大能，圣不朽，怜悯我们。
荣耀归于父、子、圣灵，从现在到永远直到永永远远。阿门。
圣上帝，圣大能，圣不朽，怜悯我们。
```

### 6. 大入口（基路伯赞美诗）
```
我们奥秘象征基路伯，向赋予生命三位一体唱三圣哉赞歌。现在让我们放下一切世俗关怀，接待万物之王，天使队列看不见簇拥着他。哈利路亚，哈利路亚，哈利路亚。
```

### 7. 恳求连祷
```
让我们向主完成我们祷告。
帮助我们，拯救我们，怜悯我们，保护我们，上帝啊，靠着你恩典。
今日我们祈求整个日子完美、神圣、和平、无罪，我们恳求主。我们祈求。
和平天使，忠信向导，我们灵魂身体守卫者，我们恳求主。
我们得罪上帝，求你赦免罪孽过犯，我们恳求主。
记念我们最神圣、最纯洁、最蒙福、荣耀上帝之母，永远童贞玛利亚，和所有圣徒，我们将自己彼此整个生命都交给基督上帝。
```

### 8. 尼西亚信经
```
开门！开门！在智慧中，让我们进去。我信唯一上帝，天父全能，创造天地和一切可见不可见万物。我信唯一主耶稣基督，上帝独生子，万世之前由父所生，光从光生，真上帝从真上帝生，受生并非受造，和父本体同一，藉着他万物被造。为了我们人类拯救我们，从天降世，由圣灵童贞女玛利亚肉身成形，成为人，在本丢彼拉多手下为我们钉十字架，被害埋葬，第三日依照圣经复活，升天，坐在天父右边，将来还要荣耀再来审判活人死人，他国度没有穷尽。
我信圣灵，赐生命主，从父出来，和父子同受敬拜同得荣耀，藉着先知说话。我信唯一圣而公教会使徒性教会。我认一次洗礼赦罪。我盼望死人复活，并且来世生命。阿门。
```
