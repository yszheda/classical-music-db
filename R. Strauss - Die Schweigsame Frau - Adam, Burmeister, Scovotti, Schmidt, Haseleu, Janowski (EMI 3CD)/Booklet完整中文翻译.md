# 《沉默的女人》（英语原文中文翻译）

1929年胡戈·冯·霍夫曼斯塔尔突然去世后，失去了优秀台本作者的施特劳斯，用他自己的话说，与"德国最优秀的诗人"进行"接触和协商"，但都没有成功。一位德国出版商的偶然访问为他联系上了奥地利作家斯特凡·茨威格。到1931年底，施特劳斯和茨威格在第一次会面就同意合作，改编本·琼森1610年的戏剧《两性人，或沉默的女人》，讲述仇恨噪音的刻薄老船长莫里修斯爵士被捉弄的故事。茨威格在他的自传《昨日的世界》中回忆，施特劳斯很高兴"给我完全自由。他说他从来不会从已经像威尔第那样裁剪标记好的歌剧文本中获得灵感；他只对诗意戏剧有反应。不过，如果我能加入一些复杂重唱，给他机会展现丰富多彩的音乐，他会很喜欢。"

在原剧中，琼森的"两性人"是一个男扮女装的侍童。茨威格将他改成了一个有真实成人情感的年轻女人，歌唱家阿明塔。莫里修斯阴谋背后真正的策划者是她的丈夫，莫里修斯的侄子亨利。琼森的特鲁威特和卡特比德被合并成费加罗式的施奈德巴特，故事情节从琼森的时代前移到18世纪80年代，也就是博马舍《费加罗》三部曲同时代。亨利阴谋中的同谋可以方便地改成歌剧歌手，而不是琼森那混杂的骑士、船长和女学者。曾经讨论过将《沉默的女人》改成快节奏带对白的轻歌剧——这是施特劳斯一直说他向往的目标，因为霍夫曼斯塔尔曾经责备他将谱好的词闷在"瓦格纳式盔甲"里。茨威格的台本刻意将本·琼森的戏剧向经典歌剧喜剧《唐·帕斯夸莱》和《塞维利亚理发师》靠拢。

这对新合作者的蜜月期持续着，施特劳斯开始定期快速收到茨威格（这是他第一次写歌剧台本）的稿件。他发现第一稿（1932年9月）"很迷人——这个喜剧想法可以放在这一体裁最优秀作品之列"，并在完成与霍夫曼斯塔尔的最后一部作品《阿拉贝拉》同时，开始为《莫里修斯爵士》（这是歌剧的工作标题）画草稿。下一稿（1932年12月）得到了瓦格纳《名歌手》中汉斯·萨克斯式的评价——当瓦尔特唱出他那稚嫩的获奖之歌时，第二小节也成功了——第三幕的评价是"完全没问题，写起来太棒了"。到1934年10月，施特劳斯已经完成了他最长的总谱之一，除了四分钟的集锦曲序曲。

三幕分别长53、71、48分钟，这部《沉默的女人》的总谱（这里呈现完整版本）不完全是快节奏轻歌剧，但它确实是故意创作的轻快、要求不高的娱乐音乐，（有时还）自我借用，充满了精湛技艺。这终于实现了施特劳斯一直在谈论的喜剧理想，自从1919年《没有影子的女人》战后首演相当平淡之后。来自《玫瑰骑士》奥克斯随从的嘈杂音乐幽灵，以及奥克塔文和瓦尔扎奇在旅馆准备的类似场景，都仁慈地浮现在这部歌剧第二幕（据称访客前来祝贺莫里修斯与化装后的阿明塔婚礼）和第三幕（歌剧团为莫里修斯家准备最终对决）中非常相似的时刻——但在这里它们被用在真正有趣的方式中。这些场景使用了新的、更轻盈的咏叹调风格带伴奏宣叙调，这是施特劳斯在1940年代他创作晚期的夏末将会完善的风格。

施特劳斯与茨威格这对新搭档的故事并没有像他们唯一完成的合作那样有幸福结局。令纳粹愤怒的是，施特劳斯在1935年6月德累斯顿由卡尔·伯姆指挥的首演中，仍然将他的台本作者名字打在了剧场海报上，但事件本身和未来项目完全被希特勒禁止犹太艺术家的种族主义政治阴谋所取代。施特劳斯后来一段时间一直坚持与流亡的茨威格通信讨论那些（别人接手完成的）后来成为《和平之日》和《随想曲》的项目，这都是徒劳。

# 《沉默的女人》（德语原文中文翻译）

1929年胡戈·冯·霍夫曼斯塔尔突然去世后，失去一位高水平台本作者的施特劳斯，用他自己的话说，与"德国最优秀的诗人""调情和谈判"，但没有成功。一位德国出版商的偶然访问联系上了奥地利作家斯特凡·茨威格。到1931年底，施特劳斯和茨威格在第一次会面就约定，合作改编本·琼森1610年的戏剧《两性人，或沉默的女人》。这部剧讲述的是憎恨噪音的老船长莫里修斯爵士被骗的故事。茨威格在自传《昨日的世界》中这样回忆施特劳斯："他想给我完全自由，因为他从来不会从已经预先裁剪好的歌剧台本中获得灵感，只会从诗意作品中获得灵感。他只希望，如果我能加入一些复杂的形式，可以为他的色彩学提供特殊的发展可能性。"

在琼森的原作中，《两性人》是一个男扮女装的侍童。茨威格将其替换成一个正确的年轻女人，带有真实成熟情感的歌唱家阿明塔。莫里修斯阴谋背后真正的牵线人其实是她的丈夫，莫里修斯的侄子亨利。琼森的人物特鲁威特和卡特比德融合成近似费加罗的施奈德巴特。故事时间从琼森的年代提前到18世纪80年代，也就是博马舍《费加罗》三部曲的同一时代。亨利阴谋中用来欺骗莫里修斯的同谋，很方便就能从琼森那群混杂的骑士、船长和"女 Collegian 们"变成歌剧男女歌手。有一段时间讨论过，是否能将《沉默的女人》转换成带对白节奏轻快的轻歌剧。施特劳斯经常表示，在霍夫曼斯塔尔纠正他之后，他会尝试剥去"瓦格纳式音乐盔甲"，他一直喜欢把歌词包裹在里面。茨威格的台本刻意将本·琼森的戏剧靠近经典歌剧喜剧《唐·帕斯夸莱》和《塞维利亚理发师》。

三幕分别长53、71和48分钟，这里完整呈现的《沉默的女人》的音乐，不能正好称为节奏轻快的轻歌剧。然而这部作品故意做成轻盈的泡沫音乐，没有高要求，音乐以惊人的精湛技艺（有时还引用自我）创作而成。这就是施特劳斯自从1919年《没有影子的女人》相当平淡的战后首演以来一直谈论的喜剧。来自《玫瑰骑士》奥克斯的嘈杂回声飘过，奥克塔文和瓦尔扎奇在酒馆准备的场景，与这部歌剧第二幕（访客到来，据称是前来祝贺莫里修斯婚礼）和第三幕（歌剧团为莫里修斯家准备最终对决）中非常相似的场景，可以很好地比较。然而这些参考在这里真的用在有趣的方式。必要场景使用新式更轻盈的宣叙调伴奏，带有咏叹调风格，这是施特劳斯在1940年代第二春的作品中将要完善的。

# 《沉默的女人》（法语原文中文翻译）

1929年胡戈·冯·霍夫曼斯塔尔突然去世后，施特劳斯因此失去了一位高质量台本作者，他"向德国最优秀诗人示好"并用他自己的话说"协商"，但这是徒劳的。一位德国出版商的偶然访问让他得以联系到奥地利作家斯特凡·茨威格。1931年底，施特劳斯和茨威格在第一次见面就达成一致，合作改编本·琼森的戏剧。

《两性人，或沉默的女人》（1610），讲述讨厌噪音的老船长莫里修斯爵士被周围人欺骗的故事。在他的自传《昨日的世界中》，茨威格回忆施特劳斯："他想给我完全自由，因为他从来不可能从已经像威尔第那样预先裁剪好的台本中获得灵感，它必须是诗意作品。他唯一希望的是，我能在文本中放入一些复杂形式，让他能在音乐中发展出一整套色彩。"

在琼森的原作中，两性人就是一个男扮女装的年轻侍童。茨威格将其变成年轻女人，一个成年人，因此带着它所需要的情感，歌唱家阿明塔。她的丈夫亨利，莫里修斯的侄子，变成了对付老莫里修斯阴谋的幕后牵线人。特鲁威特和卡特比德这两个人物被融合成理发师施奈德巴特，一种费加罗式的角色，故事从17世纪初转移到18世纪80年代，也就是博马舍写作他费加罗三部曲的时代。亨利阴谋中的同谋，他们要骗莫里修斯，可以方便地变成歌剧歌手，代替原作那些混杂的骑士、船长和女学者们。人们讨论过可能性，将《沉默的女人》做成快速推进带密集对话的轻歌剧——施特劳斯一直说他向往这个目标，在霍夫曼斯塔尔强烈指责他将文本闷在瓦格纳"盔甲"中之后。茨威格将本·琼森的剧本刻意带到古典抒情喜剧比如《塞维利亚理发师》或《唐·帕斯夸莱》附近。

两位艺术家之间的蜜月还在延长当施特劳斯收到茨威格的台本，它分成几次交付，规律而快速。他觉得1932年9月第一稿"迷人——纯粹的喜剧，它应该放在这一体裁最优秀作品之列"，并开始勾画莫里修斯爵士（作品的暂定名），同时还在完成《阿拉贝拉》，这是他与霍夫曼斯塔尔最后的歌剧。下一次交付，1932年12月，受到瓦格纳《名歌手》中汉斯·萨克斯对新手瓦尔特参赛歌曲评价的影响："第二节也成功了"；第三幕受到的欢迎是："我没什么好改的，这一幕写作完美"。到1934年10月，施特劳斯已经完成了他最长的总谱之一，只缺四分钟的集锦序曲。

三幕分别长53、71和48分钟，完整呈现于此的《沉默的女人》不完全是快速推进的轻歌剧，它是刻意轻盈的，这是辉煌的音乐，没有野心但极其精湛，有时会引用自我。这就是施特劳斯自从1919年《没有影子的女人》相当平淡的首演以来一直谈论的喜剧。我们在这里找到和《玫瑰骑士》中同样类型的嘈杂次要人物，比如奥克斯的随从，奥克塔文和瓦尔扎奇在旅馆藏着的那些人，在第三幕，这些人据称前来祝贺莫里修斯与化装后的阿明塔婚礼：第三幕，歌剧团为莫里修斯家准备最终和他对决——但这些时刻在这里用真正喜剧的方式使用。必要场景使用新型更轻盈的宣叙调伴奏，带有咏叹调风格，这是施特劳斯在1940年代最后的作品中将要完善的。
