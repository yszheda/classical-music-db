# 尼古拉·梅特纳 (1880-1951)
作者：格雷厄姆·萨瑟兰

当人们想到1917年革命后离开祖国定居西方的俄罗斯作曲家，拉赫玛尼诺夫、普罗科菲耶夫、斯特拉文斯基的名字立刻浮现在脑海。然而，还有另一位重要作曲家也走上了这条道路，多年来他的音乐一直被严重忽视。这位作曲家就是尼古拉·梅特纳，尽管他创作了许多不同体裁的作品，但人们普遍认为他最伟大的成就在钢琴音乐领域。本专辑收录的Op.25两首大型奏鸣曲和Op.51六首童话正是他成熟天才的绝佳范例。

梅特纳1880年生于莫斯科，在莫斯科音乐学院跟随当时最受尊敬的教师谢尔盖·塔涅耶夫学习。毕业后他很快作为作曲家和钢琴家建立了声誉，但十月革命改变了一切，1921年他离开俄罗斯，再也没有回来。在德国和法国生活多年后，他最终于1936年定居伦敦，并在那里一直待到1951年去世。在他有生之年，梅特纳得到许多重要倡导者的支持，最著名的就是钢琴家斯维亚托斯拉夫·里赫特，他为推广梅特纳的音乐做了大量工作。然而，直到近年来他的作品才开始被更广泛地欣赏，越来越多的录音和音乐会演出不断出现。

梅特纳与他那一代其他俄罗斯作曲家的区别在于他音乐语言绝对的独特性。他从未被影响了许多同时代人的前卫潮流所吸引，在整个创作生涯中始终忠于浪漫主义传统。他的音乐特点是丰富的对位写作、复杂的和声结构、深刻的情感严肃性，有时近乎严峻。但与此同时，他能够写出极其优美抒情的旋律，他最好的作品具有知识和情感深度，值得反复聆听。

Op.25两首钢琴奏鸣曲创作于1923至1927年间，此时梅特纳已经四十多岁，正值创作巅峰。它们代表了他在钢琴奏鸣曲创作领域成就的顶峰，每首奏鸣曲都有自己独特的性格。F小调第一奏鸣曲副标题为"叙事曲奏鸣曲"，正如标题所示，它具有强烈的戏剧性和叙事性。作品围绕几个基本动机紧密构建，在三个乐章中以相当多的对位巧思进行发展。开场乐章充满能量和冲突，有力的主题从一开始就占据主导地位。慢板更具抒情性和表现力，终曲回到开场的戏剧氛围， build up到有力而协和的结论。

E小调第二奏鸣曲被称为"夜之风"，这个标题很好地表明了它的性格。它比前一首规模更大，四个乐章而非三个，整体上更动荡不安。第一乐章以极具抒情性的主题开始，但音乐很快变得更戏剧化，激情爆发与更反思性的段落形成对比。谐谑曲轻快灵动，与随后迷人流畅的行板形成对比。终曲是最汹涌的乐章，标记为火热的急板，它积累力量达到极具强度的高潮，最后进入平静、神秘的结尾。

《六首童话》Op.51创作于1935年，比Op.25奏鸣曲晚了八年，它们展现了梅特纳探索更亲密抒情的一面。正如标题所示，每首都有一个描述性标题，唤起特定的情绪或场景，梅特纳用完美捕捉主题性格的音乐回应每个标题。它们从轻灵通透的《小云》、诙谐谐谑的《弄臣》，到冬日寂静的《雪人》、浪漫抒情的《公主与野玫瑰》、轻快灵动的《地精》，以及平静超然的《最后一朵花》。它们都是精致的小品，完美构思，充满创造性的钢琴写作，是两首大型奏鸣曲理想的搭配。

梅特纳很早就得到伟大俄罗斯钢琴家斯维亚托斯拉夫·里赫特的热情支持，里赫特有句名言：梅特纳是"二十世纪最伟大的作曲家之一"，"他的音乐是必须被保存的宝藏"。本CD由另一位俄罗斯钢琴家迪娜·帕拉基娜演奏，非常合适，她已经作为梅特纳钢琴音乐杰出诠释者建立了相当声誉。她的演奏结合了最高水平的技术掌控和对梅特纳音乐语言深刻理解，她在这里再次证明，这些音乐在今天仍然和刚创作时一样充满活力和意义。我们相信这张唱片将进一步促进对这位最独特、最重要俄罗斯作曲家日益增长的欣赏。

# 迪娜·帕拉基娜

迪娜·帕拉基娜就读于莫斯科中央音乐学校和莫斯科柴可夫斯基音乐学院，师从传奇教授列夫·瑙莫夫，这位教授的学生包括过去五十年许多最杰出的俄罗斯钢琴家。毕业后她加入莫斯科音乐学院任教，并在俄罗斯和东欧举办了众多音乐会。1992年她移居英国，在那里作为演奏家和教师建立了成功的职业生涯。

她目前在曼彻斯特皇家北方音乐学院和伦敦皇家音乐学院任教，并定期在英国和国外举办大师班。她在欧洲、美国和远东许多主要节日和音乐厅演出，为Piano Classics厂牌录制了多张广受好评的CD，包括梅特纳、拉赫玛尼诺夫、斯克里亚宾等作曲家的作品。
