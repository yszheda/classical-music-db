## 专辑介绍
```
《沃采克》从诞生之初就是一项事业：对贝尔格而言是如此，他在第一次世界大战期间始终牵挂着这部1914年开始创作、1921年完成的歌剧；对作曲家的朋友和出版商而言是如此，他们四处奔走希望作品能上演；对埃里希·克莱伯而言是如此，他在柏林以极大的耐心筹备首演，七年后又将作品重新搬上舞台并在伦敦完成了英国首演；对二战后纳粹禁令解除后推动作品复兴的信徒们而言是如此；对那些在美国首演这部作品的伟大指挥家们而言更是如此，他们当时承担了巨大的风险。

斯托科夫斯基于1931年在费城、随后在纽约开启了美国的演出历史，米特罗普洛斯则先在明尼阿波利斯、后于1951年与纽约爱乐合作演出了音乐会版（即本专辑收录的录音）。这部作品对他而言是否也是一项事业？我倾向于认为是的，而且不禁猜测他早在柏林时期就已经研究过总谱——1924年之前他一直在柏林国家歌剧院担任合唱指挥，而当时克莱伯正筹备这部作品的首演，首演时间定在1924年1月。

由于作品本身的性质，草率准备的《沃采克》演出十分罕见。我本人第一次接触这部歌剧是1949年阿德里安·博尔特指挥的音乐会版：排练极其充分，阵容强大，苏珊·丹科饰演的玛丽极为出色，给人留下了难以磨灭的印象。对我而言，1951-52演出季是《沃采克》体验的奇迹之年：12个月内我听到了三种不同语言的演出，分别是萨尔茨堡的卡尔·伯姆版、伦敦的埃里希·克莱伯版，以及米兰的米特罗普洛斯版。克莱伯当时已经与这部作品相伴近30年，他认为自己的职责就是让歌剧对演员和观众而言都显得自然，就像在他眼中那样。米特罗普洛斯显然也抱有相似的目标。到1952年，他已经在美国完成了音乐会版演出，斯卡拉歌剧院乐团是他合作的第三支乐团，演出阵容强大，由蒂托·戈比第三次出演主角，于格·奎诺德饰演上尉，完全没有漫画式的夸张处理。整场演出让人想起贝尔格的评语："这部作品应该唱得像《游吟诗人》一样。"

如今《沃采克》的演出依然不容易，但相比1951年米特罗普洛斯在卡内基音乐厅指挥时已经简单很多——当时距离柏林首演仅过去四分之一个世纪，而现在已经过去了近半个世纪。贝尔格曾为作品撰写过一套音响单元的分析注释，但他坚持认为听众在欣赏时不应进行理性分析。他是否会进一步认为，对待音符的精神比单纯的准确性更重要？我的直觉告诉我他会同意，如果我是对的，他一定会对米特罗普洛斯在纽约的演出充满热情，因为任何演出中准确性都只是故事的一半。更重要的是表演者对作品的理解程度，以及能否将这种理解传递给观众——这才是更关键的要素。本录音中 evident 的信念感使它远不止是一场伟大演出的纪念品。

乐谱中的很多音高都只是近似值，尤其是在诵唱调（Sprechstimme）段落中——这是勋伯格为《月迷彼埃罗》发明的手法，大致可以描述为"音乐化的语言"，更准确的定义是："节奏和音高被精确规定，但实际演唱时每个音只在发声的瞬间被定义，之后嗓音就像自然说话一样升高或降低。"卡内基音乐厅演出的节奏显然经过了充分的排练，但整个 cast 中只有麦克·哈雷尔将标记的音高作为比粗略参考更严格的标准。

哈雷尔不仅准确，而且演唱得非常优美，音色富有个性和温暖；他的演绎可以作为评判其他版本的标杆。艾琳·法雷尔拥有天赐的嗓音，比大多数饰演玛丽的歌唱家都更辉煌——她的表演值得称赞，尽管音高处理有些随意，但其演唱的真正美感让人很容易原谅这一点。约瑟夫·莫迪诺完美地捕捉到了上尉近乎歇斯底里的特质。

这场演出中的一切都显得轻松自然——作品难以演奏并不意味着它必须听起来艰涩。在最后一幕前的D小调悲歌这样的伟大段落中，米特罗普洛斯准确地表达了作品的精髓，他的控制创造了张力而非僵化。遗憾的是米特罗普洛斯从未在大都会歌剧院指挥过《沃采克》；伯姆指挥了大都会的首演，而作品复排时米特罗普洛斯已经去世。

这张录音是一个里程碑：它不仅记录了将这部重要作品重新引入美国的演出，也成为后世《沃采克》录音的标杆。（第一个棚录版本直到14年后才出现。）考虑到 cast 中没有母语为德语的演员，甚至纽约爱乐也是首次接触这部作品，这实在是一项非凡的成就。

哈伍德伯爵
（哈伍德伯爵曾任爱丁堡艺术节艺术总监、英国国家歌剧院总经理）
```

```
### 剧情梗概
约翰·弗朗茨·沃采克，"30岁零7个月，第二步兵团第二营第四连民兵、步兵，未受教育，理解力低下"，是团里上尉的勤务兵。为了养活玛丽和他们的孩子，他把自己交给医生做实验对象，医生当着他的面嘲笑他，把他用作医学和心理学学生的科学实验演示工具。

#### 第一幕
（第一场）军营里，沃采克正在给喋喋不休的上尉刮胡子。上尉在思索时间的流逝——他觉得时间一会儿像永恒，一会儿又只是一瞬，想到地球每24小时自转一周，他就不寒而栗。对上尉的沉思，勤务兵只是简短地回答："是，上尉先生！"上尉觉得仆人单纯得好笑，告诉沃采克他没有道德。沃采克终于回答："上尉先生，上帝不会问我那可怜的孩子出生前有没有受过祝福……我们穷人啊！钱，钱！没有钱是什么滋味！如果我是绅士，有手表、有帽子、会说体面话，我也会有德行，没错，但我们这种人在这个世界和下一个世界都是不幸的。就算我们到了天堂，肯定也得帮着打雷电！"上尉觉得沃采克本质不坏，就是"想得太多"，这是个毛病。

（第二场）日落时分的田野里，沃采克和另一个士兵安德烈斯在一起，安德烈斯正在砍树枝。沃采克被对未知的恐惧困扰，觉得这个地方透着诡异：他看到奇怪的光，想象夜里有个脑袋在地上滚，被人捡起来就变成了刺猬。迟钝的安德烈斯回唱了一首简单的猎歌。但沃采克的幻想越来越疯狂，他嘟囔着共济会的事，想象地面在他脚下裂开，最后疯狂地恳求安德烈斯逃离这个闹鬼的地方，让安德烈斯感到不安。

（第三场）玛丽在房间里和孩子玩耍。一支部队从窗下走过，走在队首的是军乐队，领头的是鼓手长。他向玛丽挥手，玛丽也回应了他的问候。邻居玛格丽特恶意地评论玛丽显然对士兵感兴趣，直到两个女人吵了起来。玛丽猛地关上窗户，把孩子抱在怀里哄他睡觉。敲门声很快把她从思绪中惊醒，沃采克在窗外，说他要回军营，现在不能进去。他语无伦次的样子让玛丽担心，她预感到有什么可怕的事要发生。她把孩子抱给他看，他连看都不看就匆匆走了。玛丽把睡着的孩子放回小床，呻吟着："啊，我们这些穷人"，"我再也受不了了。"

（第四场）第二天，医生的书房里。医生正忙着做冷酷的实验，说沃采克是精神失常的受害者，还给他制定了新的营养计划，符合他想要革新的营养学理论。沃采克一开始反抗，后来越来越迷茫、语无伦次。医生警告他，他这种固执的想法会把他送进疯人院，然后对这个可怜人有趣的病例感到很高兴，搓着手喊道："哦，我的理论，我的名声！我会不朽的！不朽！不朽！"

（第五场）玛丽家门前的街道。黄昏时分，玛丽站在那里欣赏鼓手长，他骄傲地摆出姿势，向她保证周日游行时他戴着白手套、插着大羽毛会更英俊。鼓手长居然注意到了她，玛丽喜出望外，扑进他怀里，两人一起进了屋。

#### 第二幕
（第一场）玛丽对着镜子梳妆打扮，戴着耳环。沃采克进来，看到她下意识地用手捂住耳朵，立刻起了疑心。他问耳环是哪里来的，她说是捡的。尽管沃采克显然有所怀疑，他还是转向睡着的孩子，孩子的额头湿漉漉的。"我们这些穷人啊！"他哀叹道，"天底下除了干活就是干活，连睡觉都在流汗！"他把挣的钱给了玛丽，留下她独自为自己的恶行沉思。

（第二场）上尉和医生在街上相遇。医生行色匆匆，但上尉拦住了他，医生残忍地提醒上尉他面色潮红、气色不好，警告他可能会瘫痪，甚至中风丧命，把他的朋友吓坏了。沃采克走过来，两人用玛丽不忠的暗示折磨他。等他摆脱了这两个折磨他的人，医生看着他的背影若有所思："沃采克真是个现象。"

（第三场）沃采克在玛丽家门前遇到她，语无伦次地说着"罪"，问"他"是不是就站在他现在站的地方。玛丽说街上人来人往，她"没法禁止别人走这条路"。然后她害怕沃采克会打她，哭喊道："宁可你拿刀捅我，也别碰我！我十岁的时候我父亲都不敢碰我一下！"她进屋去了，沃采克喃喃自语："宁可拿刀！我头都晕了！"

（第四场）啤酒花园里挤满了士兵，很多人都喝醉了。沃采克突然看到玛丽和鼓手长跳华尔兹，嫉妒得发狂，正要冲过去，舞曲停了。安德烈斯和其他人开始唱一首活泼的歌，有人开始做滑稽的布道。又跳了一会儿舞，一个傻瓜走到闷闷不乐的沃采克身边，说他"闻到血腥味"，又勾起了沃采克疯狂的幻想。

（第五场）深夜的军营里。沃采克在床上辗转反侧，士兵们的鼾声环绕着他，他的呻吟声吵醒了安德烈斯。他眼前闪过刀子的幻象。鼓手长走进来，吹嘘自己的 conquests，说着侮辱的话，突然扑向沃采克。沃采克怒不可遏地反击，被打得鲜血淋漓。被吵醒的士兵们冷嘲热讽了几句，又回去睡觉了。

#### 第三幕
（第一场）玛丽在房间里就着烛光读抹大拉的马利亚的圣经故事，为自己的软弱哭泣。她转向孩子，又拿起圣经，哭喊着："救世主啊，可怜可怜我吧，就像你可怜她一样！"

（第二场）树林里的池塘边。沃采克和玛丽一起来到这里。玛丽想回家，但他强迫她坐下，向她保证"你的脚不会再疼多久了"。天渐渐黑了，他回忆着他们认识了多久。疯狂再次吞噬了他。月亮升起来了，玛丽说月亮是红色的，这让沃采克想到了血。他掏出刀，刺进了她的喉咙，俯身看着她，喊道："死了！"然后跑掉了。

（第三场）小酒馆里，沃采克拼命想忘掉自己的罪行。他和玛格丽特跳舞，甚至还和她调情。她看到他手上的血，尖叫起来，吸引了其他跳舞的人的注意。他语无伦次地解释说自己割伤了自己，冲了出去，喊道："我是杀人犯吗？"

（第四场）他回到池塘边找刀，怕刀会暴露他。他把刀扔进池塘，月光下看到了上尉和医生，他走进水里想把刀捞回来，失足淹死了。那两个人听到呻吟声，感到不安，匆匆离开了。

（第五场）玛丽家门前的街上，孩子在和其他孩子玩耍。一个孩子冲他喊，说他妈妈死了。孩子们都跑去看尸体。玛丽的孩子听不懂，继续骑着竹马，越骑越快，喊着"驾！驾！"过了一会儿，他也跟着去了，还在喊"驾！"
```

## 勋伯格与克热内克作品介绍
```
阿诺德·勋伯格
《期待》

《期待》是勋伯格的独幕独角剧，基于理查德·德默尔的诗歌创作——正是这位诗人的作品此前启发了同名歌曲，以及勋伯格最伟大的室内乐作品之一《升华之夜》。玛丽·帕彭海姆的脚本塑造了一个没有名字的女性角色，被称为"女人"，她走进昏暗的森林去和情人幽会。剧情大致可以分为四场：

第一场：女人沿着车辙摸索前行，黄昏中的自然景物在她眼中呈现出恐怖的形状。尽管害怕，她还是决心进入森林寻找情人。

第二场：她向森林深处走去，依然满心恐惧，被一个形状绊倒，以为是尸体，结果只是一段树干。

第三场：女人幻听到幻看到各种景象，进一步加剧了她的恐惧。她处在半梦半醒、理性与非理性的边缘，向森林更深处走去。

第四场：这场戏占了全剧一半以上的长度。女人的情绪在恐惧与渴望、焦虑与平静之间波动。她拖着身子走到一丛树下休息，脚碰到了什么东西，正是她情人的尸体，她想象是全剧一直提到的情敌杀死了他。她时而悲痛欲绝，时而温柔怀旧，时而疯狂嫉妒，时而难以置信，最后瘫倒在地。黎明时分，她突然站起来，精神恍惚地喃喃自语着走开："我在找……"

理查德·哈尼-贾丁

恩斯特·克热内克
《交响挽歌》

1945年9月15日，作曲家安东·韦伯恩在奥地利米特西尔散步时，被一名美国士兵误杀。消息传来，整个音乐界都感到震惊和悲痛，恩斯特·克热内克也不例外，他创作了《交响挽歌》作品105号，副标题为"纪念安东·韦伯恩"。

克热内克早期的音乐风格多样，既有不协和的无调性作品，也有他自己描述为"带爵士调味品的调性音乐"。早年他曾反对勋伯格及其著名弟子（尤其是韦伯恩）的十二音音乐所代表的极端现代主义，声称他们的音乐故意激怒和疏远听众。事实上，克热内克曾发表过一系列贬低这一运动的言论，明确将自己置于勋伯格圈子之外。然而从1930年代左右开始，克热内克逐渐转向十二音音乐，在很多人看来这似乎是矛盾的。到1930年韦伯恩在广播中播放克热内克的作品时，克热内克的创作实际上已经被认为与勋伯格学派属于同一阵营。那次广播开启了两位作曲家的密切交往，很快人们就会同时提到韦伯恩和克热内克的名字，年轻作曲家的思想和音乐中都能感受到韦伯恩的影响。

不出所料，这部为弦乐团创作的短小单乐章挽歌深情地秉承了韦伯恩的美学，尤其在十二音序列的处理上更是如此：这是弟子献给敬爱的导师的动人而优雅的致敬。

理查德·哈尼-贾丁
```

## 德语介绍（翻译）
```
阿尔班·贝尔格与阿诺德·勋伯格的肖像（美国音乐档案馆资料）

《沃采克》的历史上有很多人都将推广这部歌剧视为己任。阿尔班·贝尔格在1914年至1921年的一战期间创作了这部作品，他的朋友和出版商经过多方努力才使《沃采克》得以首演。首演指挥是埃里希·克莱伯，他在排练时表现出了极大的耐心，七年后又指挥了伦敦的舞台首演。二战后纳粹禁止演出这部作品，是贝尔格的追随者们重新恢复了它的上演，而在美国首次指挥这部作品的那些伟大指挥家们更是承担了极大的风险——当时这完全是一次冒险的尝试。

利奥波德·斯托科夫斯基于1931年首先在费城、随后在纽约指挥了这部歌剧，迪米特里·米特罗普洛斯也指挥了音乐会版演出，先是在明尼阿波利斯，1951年又与纽约爱乐合作（即本唱片收录的演出）。我认为米特罗普洛斯也与这部作品有着特殊的联系。他可能早在柏林时期就已经研究过总谱，1924年之前他一直在柏林国家歌剧院担任合唱指挥，而当时克莱伯正准备将这部作品搬上舞台，首演定于1924年1月。

这部作品的性质决定了它的演出通常都是经过深思熟虑和精心准备的。我本人第一次接触《沃采克》是1949年阿德里安·博尔特指挥的音乐会版，当时的排练极其细致，阵容强大，苏珊·丹科饰演的玛丽非常出色，给人的整体印象是震撼性的。对我来说，1951/52演出季是《沃采克》体验的丰收年：十二个月里我听到了三种不同语言的演出，分别是萨尔茨堡的卡尔·伯姆版、伦敦的埃里希·克莱伯版和米兰的迪米特里·米特罗普洛斯版。克莱伯当时已经研究《沃采克》近三十年，他的首要目标是让歌剧对演员和观众来说都显得自然，就像他自己感受到的那样。米特罗普洛斯显然也追求类似的目标。到1952年，他已经通过在美国的音乐会演出对总谱了如指掌，斯卡拉歌剧院乐团是他合作的第三支乐团，演出阵容一流，蒂托·戈比第三次饰演主角，于格·奎诺德饰演上尉，没有任何漫画式的夸张。整场演出让人想起贝尔格的评语，他说这部歌剧"应该唱得像《游吟诗人》一样"。

《沃采克》直到今天依然难以演出。1951年米特罗普洛斯在卡内基音乐厅指挥时，困难要比现在大得多，毕竟距离柏林首演仅仅过去了25年。贝尔格为歌剧附加了一套音响单元划分的方案，但他反对听众在欣赏时进行相应的分析。人们不禁会问，他是否会认同这样的观点，即把握音符的精神内涵比单纯机械地复制更重要。我坚信贝尔格会同意这种看法，如果真是这样，他一定会为米特罗普洛斯在纽约的演出感到振奋，因为这场演出再次证明，准确性只是诠释的一个方面。更重要的是，音乐家们完全吃透了作品，能够将自己的见解传递给观众。这一点在本录音中体现得非常明显，因此它远不止是对一个伟大夜晚的回忆。
```
