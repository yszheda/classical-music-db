# 多尼采蒂：《罗翰的玛丽亚》

《罗翰的玛丽亚》创作于1843年，为维也纳而作，多尼采蒂之前在维也纳上演的《夏莫尼的琳达》已经获得相当成功。首演于同年6月5日，伟大女高音威廉明娜·施罗德-德弗里恩特饰演标题角色。歌剧获得好评，多尼采蒂本人认为这是他最好的作品之一。

故事发生在路易十四统治时期的巴黎。玛丽亚是罗翰伯爵里卡尔多的妻子，她之前与恩里科·迪·吉斯公爵相恋。当恩里科从流亡归来，旧情复燃。里卡尔多怀疑发生了什么，向恩里科提出决斗挑战。恩里科被杀死，玛丽亚悲伤而死。

这是多尼采蒂最有力的晚期歌剧之一，戏剧结构特别强大，一些旋律创作最具灵感。标题角色是意大利女高音曲目最具挑战性的角色之一，需要极好的声乐灵活性和深刻的戏剧强度。

本录音来自1962年米兰现场广播，记录了战后时期最重要意大利女高音之一弗吉妮亚·泽阿尼饰演标题角色的演出。在费尔南多·普雷维塔利——意大利曲目最有经验的意大利指挥之一——指挥下，这场演出捕捉到了多尼采蒂悲剧杰作所有激情和戏剧。

Myto骄傲地呈现这份重要历史录音，记录了二十世纪伟大女高音之一的重要演出。

# 加埃塔诺·多尼采蒂 (1797-1848)

加埃塔诺·多尼采蒂1797年生于贝加莫，出身贫困家庭。他在贝加莫音乐学校跟随作曲家西蒙·迈尔学习，迈尔发现了他非凡的天赋，帮助他继续在博洛尼亚音乐学院学习。到26岁时，他已经创作了超过十部歌剧，很快确立了自己作为意大利歌剧主要作曲家之一的地位。

在1830年代和1840年代，他创作了一系列引人注目的歌剧，包括一些最著名作品：《安娜·博莱娜》(1830)、《爱之甘醇》(1832)、《卢克雷齐娅·博尔贾》(1833)、《拉美莫尔的露琪亚》(1835)、《罗伯特·德弗罗》(1837)、《宠姬》(1840)、《夏莫尼的琳达》(1842)、《唐·帕夸勒》(1843)，以及《罗翰的玛丽亚》(1843)。他令人难以置信的创作力配上非凡的旋律天赋和敏锐的戏剧感。他在罗西尼和威尔第之间统治着意大利歌剧，他最好的作品至今仍在舞台上演。

1845年他健康开始衰退，久病之后，1848年在贝加莫去世，享年51岁。

# 弗吉妮亚·泽阿尼

弗吉妮亚·泽阿尼1926年生于罗马尼亚。1948年首演，很快确立了她作为她那一代最重要女高音之一的地位，尤其是在意大利美声曲目。她在世界所有主要歌剧院演唱，包括米兰斯卡拉歌剧院、纽约大都会歌剧院、伦敦科文特花园等等。她演唱多尼采蒂、贝利尼、威尔第作品特别受到赞赏，以优美音色和完美技巧闻名。她在印第安纳大学音乐学院任教多年，一直演唱到1980年代。2010年去世。

# 费尔南多·普雷维塔利

费尔南多·普雷维塔利1907年生于意大利阿德里亚。他在米兰音乐学院学习，很快成为意大利最重要指挥之一。1936年至1953年他担任米兰RAI交响乐团首席指挥，后来与意大利许多主要乐团和歌剧院合作。他以意大利歌剧作品特别知名，指挥了许多十九世纪意大利曲目的重要演出。1985年去世。

## 剧情梗概

### 第一幕

恩里科·迪·吉斯在决斗中杀死一人被迫流亡，秘密返回巴黎。他来到罗翰伯爵里卡尔多的府邸，他的旧情人——伯爵的妻子玛丽亚住在这里。恩里科和玛丽亚见面，旧爱重生。玛丽亚催促恩里科逃走，但他拒绝了。里卡尔多意外回家，恩里科被迫躲藏。里卡尔多怀疑有人躲藏，但玛丽亚成功欺骗了他。当里卡尔多离开后，恩里科出来，他和玛丽亚计划当夜一起逃走。

### 第二幕

在路易十四的宫廷，一切都在庆祝。里卡尔多发现了玛丽亚和恩里科之间的真相。他与玛丽亚对质，玛丽亚承认了一切。里卡尔多向恩里科挑战决斗。

### 第三幕

决斗进行。恩里科受了致命伤。他被带回玛丽亚的房间。他死在玛丽亚怀中。玛丽亚悲伤过度，也死了。
