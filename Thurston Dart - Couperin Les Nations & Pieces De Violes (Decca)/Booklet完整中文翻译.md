右页 - 曲目注释：
```
吕利的幽灵在库普兰著名的音乐神化中格外醒目。对于比这位嫉妒的佛罗伦萨人晚了一辈的库普兰来说，吕利就是"无与伦比者"——因为当吕利1687年去世时，伟大的库普兰才只有十九岁，而且吕利本人并没有戏剧野心，也从未感受到法国音乐独裁者的约束影响。1725年，也就是吕利去世三十年后，库普兰出版了他对这位深深烙印在法国音乐之上人物的音乐颂词，标题为《为纪念无与伦比的吕利先生而作的器乐协奏，冠名神化》。库普兰在前言中说，这部作品"可以用两台大键琴演奏，也可以用其他乐器"，把选择留给演奏者。所以，就像许多古老法国"交响曲"或器乐作品一样，它可以演奏为简单三重奏鸣曲，也可以是大键琴二重奏，甚至可以是室内乐团作品。我们现代纯粹主义者对Recorder确切类型或法国号音高争得不可开交，伟大的弗朗索瓦·库普兰不会对他们有多少同情……

库普兰的《吕利神化》是毫不掩饰的标题音乐，是这类成对作品中的第二部，第一部是为了纪念库普兰另一位伟大音乐英雄科雷利。在开篇的庄重段，吕利被发现在极乐净土（是天国的那个，不是巴黎人熟悉的香榭丽舍），在那里他和其他音乐精灵一起合奏。天神墨丘利，那天使信使，出现宣布阿波罗——太阳神，艺术的保护神——即将降临——这里毫无疑问也隐晦地提到了吕利伟大的赞助人路易十四，他在宫廷芭蕾中最喜欢扮演的角色就是"太阳王"。阿波罗出现了，上场音乐标记着"高贵"。他把小提琴献给吕利，还有缪斯神山帕纳塞斯的一席之地。这让吕利一些老对手无法接受，他们的嫉妒被有趣地描绘在《地下流言》这个段落中，也就是"地下的抱怨"。他们的抱怨延续到下一段，悲叹"由长笛或小提琴极为柔和地演奏"，额外标记了"悲伤地"。

吕利飞向帕纳塞斯，在那里受到科雷利和意大利缪斯女神的欢迎，段落标记着意大利风格
```

## 扫描页 6 (HIPPO_20220227_0006.jpg)

```
"广板"。吕利用优雅的三拍子咏叹调感谢阿波罗，阿波罗随即劝说吕利和科雷利融合法国和意大利风格，从而实现"音乐之完美"。他们在随后两首大型作品中做到了。第一首是"序曲形式的尝试"，法国风格，其中吕利和法国缪斯演奏一部分，科雷利和意大利缪斯风度翩翩地演奏另一部分。（库普兰没说谁应该通奏低音——也许是阿波罗？）序曲本身就是典型吕利式法国形式，宏伟开头加上活泼赋格段，然后回到开场情绪。序曲之后是两首新咏叹调，两把无低音小提琴；第一首咏叹调中，吕利演奏主题科雷利伴奏，第二首角色互换。

演奏完法国序曲，一行人继续演奏一首意大利奏鸣曲，标题是"帕纳塞斯的和平"，值得称赞的目的就是融合两种伟大民族风格。作品是典型意大利教堂奏鸣曲四乐章结构，遵循慢-快-慢-快的模式，帕纳塞斯实现了和平，库普兰两位伟大音乐英雄携手合作，融合"法国品味与意大利"——唯一条件就是在法语中，意大利词语如"Sonata"、"Cantata"等等要法语化为"Sonade"、"Cantade"等等。但是，正如G.K.切斯特顿警告过我们，人类喜欢玩"欺骗先知"的游戏。法语用法最终决定"Sonate"、"Cantate"才是 preferred 形式。库普兰的音乐比他拼写活得更久。

查尔斯·卡德沃思

这部四个组的集子名为《各国，三重交响曲奏鸣曲与组曲》，1726年在巴黎出版。库普兰在前言中解释说："这些三重奏有些是几年前创作的；虽然手稿抄本一直存在，但我不信任抄本，我知道抄写员有多粗心。我不时增加曲目数量，我认为它们能让真正音乐爱好者满意。这个集子中第一首奏鸣曲是我创作的第一首，确实也是法国创作的第一首。它的经历非同寻常。我被科雷利先生的奏鸣曲深深打动，只要我活着，我就会喜爱他的作品，再加上吕利先生的作品，我冒险创作了一首，就在我听过科雷利奏鸣曲的地方演奏。我知道法国人对任何外国创新都很严苛，我也不太自信，所以我耍了个小花招保护自己。我假装说，一位亲戚——他确实为撒丁尼亚国王服务——寄给我一首意大利新作曲家的奏鸣曲。签名其实就是我自己名字重新排列字母变成意大利名字。这首奏鸣曲被热情接受了，我也就不多说了。这件事鼓励我继续创作，我的意大利化名字在伪装下为我赢得了很多掌声。

幸运的是，我的奏鸣曲反响非常好，我的小计谋也没让我脸红。我于是把这些早期奏鸣曲和我后来创作的放在一起，没有做什么重大修改或增添。我只是把它们和长篇舞曲组曲放在一起，奏鸣曲就像是前奏曲或引子……"

正如库普兰指出，每个组都以意大利风格教堂奏鸣曲开始，这些奏鸣曲和亨利·普赛尔庄重的三重奏鸣曲有很多相似之处。风格上以对位为主，这类奏鸣曲由一连串对比乐章构成，每个乐章都有独立清晰的主题。"法兰西"开篇的奏鸣曲被认为创作于1692年。它包含八个段落：庄重-愉悦-庄重-愉悦-庄重-活泼-优雅（咏叹调）-愉悦。

"法兰西"继续进入库普兰称之为"交响曲组曲"——也就是法国风格舞曲组曲。组曲照例以高贵的阿勒曼德开始；接着是两首库朗特，第一首比第二首稍慢，然后是萨拉班德（"庄重"），吉格（"愉悦"），然后是扩展夏康
```

## 扫描页 7 (HIPPO_20220227_0007.jpg)

```
（库普兰标记了各种情绪和风格变化；为了变化，两个段落被演奏为大键琴独奏），最后是加沃特和小步舞曲。

和"法兰西"一样，"西班牙"也以教堂奏鸣曲开始；它也创作于1692年。性格和色彩都非常阴郁——它原本是否为管风琴通奏低音创作？——它包含两首迷人的温柔咏叹调。奏鸣曲以固定低音变奏结束，主题最初由低音维奥尔奏出（大键琴伴奏并演奏精心写出的键盘段落，库普兰称之为"嬉戏"）。

这个固定低音主题在17世纪后半叶的欧洲各地都很常见；它的大调版本被普赛尔用作大键琴独奏曲，也是巴赫无与伦比的《哥德堡变奏曲》主题基础。就像普赛尔的恰空（在相关主题上），旋律从一个乐器传到另一个乐器，其他乐器用精致对位做出评论。这首优美奏鸣曲之后就是组曲，照例以阿勒曼德开始（"优雅"）；经过一对对比库朗特之后，组曲继续到萨拉班德（"庄重"），充满力量和表现力，然后是复杂的缓吉格（"中板"）。短小的加沃特（"温柔，不拖沓"）铺垫了轮旋曲（"深情"）。经过轻松的布雷（每段反复都用库普兰自己的变奏），组曲以宏伟的帕萨卡利亚结束（高贵，显著）；这个乐章最快乐的笔触包括无伴奏小提琴的短小二重奏，以及刚劲的号角吹出之后立刻接上温柔段落，三把弦乐器你追我赶。这个段落的特殊效果因为低音维奥尔必须演奏的极高音区而更加突出。

整部《各国》都是为相同的破阵合奏配置写作：两把小提琴，一把维奥尔琴和大键琴通奏低音——这种乐器组合在17世纪末18世纪初非常受欢迎。大多数北欧作曲家为这种组合写作时，都一致偏爱低音维奥尔纤细 delicate 音色，而不是大提琴更刚劲的声音，因为他们认为大提琴音色会压住小提琴之间对话。本录音使用的文本基于库普兰全集中第九卷（由鸟出版社出版），我们充分考虑了法国特殊演奏传统，比如不平均音符、滑音、重音以及舞曲乐章正确速度。我现在确信，在1660年到1720年左右大量器乐作品中，连音pair的十六分音符应该按照苏格兰切分音节奏演奏——第一个音符比第二个短很多——所以这种特殊演绎方式贯穿了整张录音。本录音中数量极多装饰音的诠释都基于库普兰自己在他大键琴书中解释。

瑟斯顿·达特
```
