# 专辑基本信息

## 专辑名称

  - Sanctus Seraphin, Venezia 1734
- Lawrence Dutton - 中提琴/viola

- David Finckel - 大提琴/cello
  - Jean-Baptiste Vuillaume, Paris 1825
